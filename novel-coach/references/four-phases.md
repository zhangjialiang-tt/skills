# 四阶段故事炼金流程 — 详细质询清单

本文档展开每种操作模式下的质询问题。SKILL.md 保留流程骨架，此处为实际执行时的逐阶段追问。

---

## CHALLENGE 模式（全流程质询）

从 Phase 1 开始，逐阶段质询。每阶段确认后才进入下一阶段。不跳过步骤。

### Phase 1: 核心概念与红线测试

验证故事的商业可行性。

1. **一句话核心梗**：谁，在什么极端环境下，想要什么？（必须包含冲突预演）
2. **钩子验证**：开篇前三章，凭什么留住读者？（极致危机？反差身份？金手指爽感预告？）
3. **商业价值**：卖给谁看？核心情绪价值是"爽"、"甜"还是"烧脑"？

> 若核心梗逻辑不通或缺乏吸引力，**在此阶段直接提出重构建议**，不进入下一阶段。

**终止条件**：核心梗无法通过红线测试（致命逻辑硬伤/市场毒点/高度雷同）。

### Phase 2: 世界与人设压力测试

1. **力量体系/阶层跃迁**：明确"低-中-高"的鄙视链与晋升门槛。升级动力是什么？阻力是什么？
2. **反派设计**：设计价值观、利益、情感上与主角**绝对对立**的对手。不能是送经验的木桩。
   - 追问：反派的动机读者能理解吗？反派有没有自己的"正确"？
3. **主角缺陷**：内心缺失什么？这种缺失如何阻碍成功？完美是无聊的。
   - 追问：缺陷如何与主线剧情产生因果联系？

### Phase 3: 结构蓝图与节奏控制

1. **黄金三章设计**：推演前三章情绪曲线（如：压抑→爆发→期待）
2. **主线拆解**：全书最大高潮（大结局画面）→ 倒推关键转折点（中点、灵魂黑夜）
3. **第一个副本/事件**：设计完整"起承转合"，必须包含确立付费意愿的"小高潮"
   - 追问：第一个副本结束后，读者能清晰预期什么？

### Phase 4: 局部打磨与实战推演

针对具体段落：

1. **节奏扫描**：是否水字数？无效对话？建议删减或增加冲突密度
2. **爽点计算**：检查"铺垫→压抑→爆发"链条是否完整。高潮是否有力？
3. **逻辑补丁**：修复 OOC 或设定冲突

## FOCUS 模式（单刀直入诊断）

用户指定具体问题，直接进入 Phase 4 思路，针对指定内容诊断。

触发场景："这段写得怎么样""帮我看看这个设定有没有问题""卡文了""爽点不够怎么办"

### 常见诊断角度

| 问题类型 | 诊断方法 |
|---|---|
| 卡文 | 回溯上一次有意义的选择点，检查是否回避了冲突 |
| 爽点不够 | 检查铺垫是否足够压抑、爆发是否延迟 |
| 设定矛盾 | 列举矛盾点，追溯最早出现不一致的节点 |
| 人物 OOC | 对比人物初始设定与当前行为，标注偏离 |
| 节奏拖沓 | 逐段标注"信息增量"，删除无增量段落 |
