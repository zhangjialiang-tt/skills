# 阶段 C 细则：视觉一致性合同

> 出处：源流程《明天的来电》试播集生产包（2026-10-29）。

## C1. 三份合同，各管一件事

| 文件 | 管什么 | 禁止写什么 |
|---|---|---|
| character_bible.md | 每个稳定出现角色的外貌/服装/表演范围 | 性格小传、前史——叙事内容归剧本 |
| location_bible.md | 空间关系（ASCII 俯视图）、关键物体契约 | 与镜头无关的世界观设定 |
| visual_style.md | 光源、摄影、调色、负面清单 | 具体剧情 |

不生成无法验证的冗长世界观——视觉合同是"合同"，不是设定集。

## C2. 固定 token（提示词的引用源）

每份合同 §1 放一段**中英双语的固定描述 token**，后续所有提示词逐字复制它，不允许现场改写。token 要短而可判定：写"浅灰色圆领卫衣，袖口偏长盖住手腕一半"，不写"穿着随意居家"。

风格 token 通用底稿（按项目增删）：

```
中文：写实电影质感，<场景类型>，竖屏 9:16，等效 35mm 焦段视角，f/1.8 浅景深，
低调布光，低饱和度，阴影偏冷，真实皮肤质感，轻微画面颗粒，无风格化滤镜
English: photorealistic cinematic look, ..., vertical 9:16, 35mm-equivalent framing,
f/1.8 shallow depth of field, low-key lighting, desaturated palette, cool shadows,
realistic skin texture, subtle grain, no stylized filters
```

负面清单通用底稿：过饱和、AI 光滑皮肤、塑料质感、HDR 光晕、卡通/插画风、镜头炫光滥用、多余人物、屏幕文字乱码。

## C3. 三分法（每份合同的骨架）

每份合同必须分三节，逐条列：

1. **必须始终一致**：跨镜漂移会直接穿帮的项（面部特征、发型、服装、道具几何、光源规则）。
2. **允许因镜头变化**：景别带来的细节可见度、受光面积、表情强度——写清楚允许变什么，模型才不会把"必须"项一起漂掉。
3. **需参考图片确认**：每张参考图一行（编号/用途/状态"待生成待人工确认"）。参考图生成后只允许重生成，不允许改提示词里的 token——防止契约漂移。

## C4. 防漂移两条硬规则

1. **首帧派生规则**：所有含人物的镜头，首帧优先从定版人物参考图派生（图生图），不从文字独立文生图。平台若不支持参考图机制（**能力待平台文档验证，不得预设**），退化为"同一 token 全文 + 逐镜与参考图人工比对，不达标重生成"。
2. **伏笔道具绑定**：B 阶段登记的伏笔道具，两状态的参考图必须出自同一张母版（源案例：门链"挂上/垂开"两张图同机位同焦段），并在两镜提示词中互相引用。

## C5. 空间关系要画出来

用 ASCII 俯视图锁定房间几何（床、门、窗、柜的相对位置与画左右关系）。阶段 F 的导演审查要拿它核对每镜的轴线、出画/入画方向、转头方向——没有这张图，轴线矛盾（源案例：S13 向画面左转头但门在画右）只能靠人脑想象，必然漏。

## C6. 光源契约（夜景悬疑类项目的重中之重）

- 枚举全片光源（数量 ≤3），每个标色温、行为规则（何时存在、何时熄灭）。
- 光影即叙事：某光源的熄灭/出现本身可以是剧情拍点（源案例：走廊灯 00:52 熄灭 = 威胁升级），必须在合同里写成规则而不是临场发挥。
- 暗部规则：保留 5–10% 亮度细节，禁止死黑——纯黑区域是 AI 生成噪声与色带的温床。
