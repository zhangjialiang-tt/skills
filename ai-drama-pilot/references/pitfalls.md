# 实战坑清单（pitfalls）

> 出处：源流程《明天的来电》试播集生产包（2026-10-29）阶段 F 审查与制作全程沉淀。每条含源案例标注。**写分镜（阶段 B）和提示词（阶段 D）前必读**；阶段 F 审查时按编号逐条核对。编号 PIT-01…PIT-12 是条目 ID，与审查问题的 P0/P1/P2 优先级是两套体系，不要混用。

## 一致性类

**PIT-01. 台词时长余量不足**
台词字数 ÷ 语速（中文口播默认 3.5 字/秒）必须 ≤ 镜头窗口 − 0.5s。
源案例：12 字台词在 3.7s 窗口余量仅 0.3s，脚本校验抓出，判 P1 缩句。写分镜时就算，别等配音时才发现。

**PIT-02. 轴线与转头方向矛盾**
镜头机位一变，"画面左右"就变了。任何"看向 X"的镜头，X 在画面哪一侧必须能从空间俯视图推出来。
源案例：S13 与 S04 不同轴时按习惯写了"向画面左方转头"，而同轴推导下门在画面右侧——提示词会把人物转向没有门的方向。

**PIT-03. 同一事件的时间码多处不一致**
一个声音事件（敲门、留言、灯灭）的触发时间码，在剧本、分镜、声音计划、剪辑计划里必须是同一个数。声桥（声音先入 0.3s）最容易写出 2–3 个版本。
源案例：敲门声出现 14.5/14.2/13.7 三个值，门外声音出现 36.7/37.2/37.5 三个值，全部判 P1 统一。

**PIT-04. 伏笔道具状态漂移**
"前面埋、后面收"的道具（可开合/可移动/有状态的任何东西），每个状态出现在哪一镜要登记，两状态参考图必须同源。
源案例：门链 S04（挂，不引人注意）→ S11（挂，明示）→ S14（垂开，揭示）；若 S04 生成成垂开状态，结尾揭示直接失效。

**PIT-05. 角色跨镜漂移**
每多一个独立文生图的首帧，人物就多一次漂移机会。含人物镜头的首帧从定版参考图派生（平台能力待验证时，用同一 token 全文 + 逐镜人工比对）。
源案例：14 镜中 6 镜含人物，character_bible 因此新增"首帧派生规则"一节。

## 生成风险类

**PIT-06. 屏幕文字必然乱码**
任何屏幕内容（锁屏、消息、播放条、波形）都不交给模型生成——生成"纯亮屏/黑屏"，全部 UI 后期叠加。提示词必须显式写"无任何文字图形"，且负面清单带上。

**PIT-07. 接触类动作形变**
头贴门板、手扶门框、背靠墙——接触点的穿插是形变高发区。要么留物理间隙（"耳朵距门板几厘米，未接触"），要么把接触动作移出画面。
源案例：S06 耳贴门板改为"留 3–5cm 间隙"，S09 贴墙列为全片唯一高风险镜并配三层替代。

**PIT-08. 手指与脚趾**
特写里手指畸形无法掩盖。手部特写镜首帧必须人工筛；能不露脚就不露（源案例："赤足"在视觉合同阶段改为"深灰短袜"，一条 Edit 消掉一类风险）。

**PIT-09. 大角度转头**
转头超过约 30°，多数图生视频模型的面部会崩。把角度写死在提示词里；更大视角变化用两个静帧硬切实现。

**PIT-10. 让模型做它做不了的事**
鱼眼畸变、圆形暗角、屏幕 UI 动画、片名、字幕、推镜变焦——这些全部是后期工序，写进提示词只会污染画面。分镜的"推荐方式"字段就是干这个的：静帧后期镜的动态生成本身就是可选项。

## 流程类

**PIT-11. 用占位符冒充完成、用宣称代替验证**
"已生成/已测试/支持 XX" 只能在实际执行过且看到结果后说。平台能力（时长档位、参考图机制、首尾帧）一律"待验证"。未生成任何视频时，汇报里不得出现"已生成视频"。

**PIT-12. 历史文档与活文档混改**
评审/审查文档引用旧台词旧时间码是**证据**，保持原样；screenplay/storyboard/audio_plan 是**活契约**，必须同步更新。区分方法：脚本扫描"旧引用残留"，命中历史文档属预期，命中活文档即为缺陷。

## 附：本项目验证出的"便宜救命稻草"

按性价比排序，生成失败时依次启用：

1. 静帧 + 后期动效（光效呼吸 / Ken Burns / 位移抖动 / 两帧溶解）——零生成成本
2. 降级姿态重新生成（去掉接触、去掉大动作）
3. 拆镜（一个动作拆两静帧硬切，靠声音缝合）
4. 实拍或图库素材替代个别空镜/道具特写（注意版权审查）

源项目最坏情况测算：14 镜全部退化为"静帧 + 后期"，成片依然成立——这就是每镜必须写替代方案的原因。
