# 阶段 A+B 细则：剧本与分镜

> 出处：源流程《明天的来电》试播集生产包（2026-10-29）。文中"程野""门链"均为该项目的示例标注。

## A1. 多版本竞争法（先发散再收敛）

先写 **3 个差异明确的版本**，每个版本用一种不同的张力策略，不允许三个版本只是同一故事的三次润色。常用的三种策略（可替换，但必须真差异）：

| 策略 | 核心动作 | 适用 |
|---|---|---|
| 悬念前置 | 异常事件在前 3 秒落地，冲突靠信息差推进 | 快节奏平台（抖音/Reels） |
| 情绪优先 | 人物先行，异常稍后，靠微表演驱动 | 有表演能力/情绪题材（注意：面部长表演是 AI 生成最高风险项） |
| 反转重构 | 结尾信息重新解释前文，前置一个可在结尾兑现的伏笔道具或动作 | 需要结尾"新信息"而非重复悬念 |

## A2. 评审矩阵（一次性选版）

六项标准逐版打分，强/中/弱 + 一句证据：

1. 观众能否在 10 秒内理解基本冲突？
2. 前 3 秒钩子是否足够明确？
3. 人物行为是否符合情境？
4. 结尾悬念是否逻辑自洽？
5. AI 视频是否容易实现？（动态镜头数、动作复杂度、一致性风险）
6. 是否存在多余对白和无效镜头？

选版规则：
- **允许杂交**：采用 A 版骨架 + 吸收其他版本的最强元素（源案例：A 骨架 + C 版的门链伏笔回收）。杂交必须在评审文档里写明吸收了什么、为什么。
- **淘汰必须记录理由**，防止后续阶段有人想把淘汰版加回来。
- **一次性选定，不循环重写**。后续审查只对合并后的成稿做逻辑复核，不再重开选版。

## A3. 正式剧本格式

- 场景头（内/外景·地点·时间）+ 动作行 + 引用块形式的 VO/音效行，**每镜带时间码**（与后续分镜一一对应）。
- 剧本末尾附"要点备案"：故事基线各要素的兑现位置对照表——这是阶段 F 编剧审查的核对基准。
- 对白写作：口语化、短句；**全片尽量无画内开口对白**（用电话语音 VO、画外音、文字消息替代）——规避口型生成这一 AI 视频最大难点之一。

## B1. 分镜固定字段（逐镜 13 项）

每个镜头在 `storyboard.md` 中必须给出：

shot_id｜时间区间及持续时长｜场景与景别｜画面内容｜角色和道具｜摄影机位置及运动｜角色动作｜光照与色调｜对白/旁白/音效｜前后镜头衔接｜推荐方式（图生视频 / 静帧后期 / 特殊剪辑）｜生成难度（低/中/高）｜失败替代方案

同时在文首给一张镜头总览表（shot_id/区间/时长/景别/方式/难度）和时长合计算式。

**`shot_list.csv`（机读唯一源，列名即脚本契约，不要自创）**

`verify_timeline.py` 默认按下列列名读，改列名就得同时传 `--start-col/--end-col/--duration-col`：

| 列 | 必需 | 说明 |
|---|---|---|
| `shot_id` | 是 | 与 storyboard、提示词文件名、manifest 保持一致 |
| `start_s` / `end_s` / `duration_s` | 是 | 十进制秒；必须满足 end−start == duration |
| `scene` / `shot_size` / `camera_move` | 否 | 供制片统计与后续剪辑参考 |
| `method` / `difficulty` / `fallback` / `prompt_file` | 否 | 与 manifest 同名同值，不要另起一套代号 |

**时间码只保留一套权威值**：`shot_list.csv` 的数值秒是唯一机读源，`storyboard.md` 的 `00:00–00:04`、
manifest 的 `time_range`、audio_plan 的时间码全部由它换算（同一份数据的两种呈现，不是三处各写一遍）。
修改分镜先改 CSV 再同步其余各处——这与 pitfalls PIT-03 是同一个失效模式。

## B2. 时长数学（三条硬规则）

1. **闭合**：所有镜头时长之和 == 成片总长；区间首尾相接无重叠无缝隙。写完立即跑 `<skill>/scripts/verify_timeline.py shot_list.csv --total <目标秒数>`（`<skill>` = SKILL.md 所在目录）并确认返回 0——**漏掉 `--total` 时脚本不校验目标总长（仅打印 WARNING，仍会返回 0），会放过总时长不符的分镜**——通过才进阶段 C。
2. **台词余量 ≥0.5s**：台词时长 ≈ 字数 ÷ 语速（中文口播默认 3.5 字/秒），必须 ≤ 所在镜头窗口 − 0.5s（留呼吸与剪辑安全边）。源案例：12 字台词在 3.7s 窗口里余量仅 0.3s，评审判为 P1，缩句后余量 1.1s。
3. **动作配额**：一个镜头只安排一个核心动作。转身、走位、取物、读屏混在一镜里，是生成失败和观众看不清的双重原因。

## B3. 分镜阶段就要定下的全局约定

- **推荐方式的配比**：图生视频镜头越多成本与风险越高；钩子镜、表演镜值得动态生成，空镜、特写道具、光影变化类镜头默认"静帧后期"（一张图 + 后期动效/音效，成本近零）。源项目配比：14 镜中动态 9、静帧 5。
- **伏笔道具登记**：凡"前面埋、后面收"的道具（源案例：门链，S11 挂上→S14 垂开），此刻登记它的两个状态出现在哪两镜、必须同参考图同机位。这是结尾"新信息"的物理承载，也是一致性高风险点。
- **声音骨架表**：分镜文末放一张"时间码 → 事件"粗表（敲门/留言/灯灭/静默等），阶段 E 在它上面细化。声音驱动的镜头（如空镜+敲门声）要在画面内容里写明"本镜由声音驱动"。
