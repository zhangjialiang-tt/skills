# S6 数据聚合 — Skill IR

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | S6 |
| 一句话功能 | 将 S0-S5 分散输出合并为一章一行的中央数据表 |
| 运行模式 | append / update / rebuild |
| 允许写入字段 | 汇总字段、派生统计字段（emotion_range, payoff_density_flag, major_payoff_flag, strong_hook_flag, review_priority） |

## 触发条件

### 应触发
- "聚合数据"、"合并中央表"、"生成汇总表"
- "数据合并校验"、"导出数据"

### 不应触发
- 文学分析 → S1-S5
- 可视化 → S7
- 公式提炼 → S8

## 输入依赖
- S0 chapter_index
- S1-S5 全部 records
- existing_master_table（非首批）

## 输出消费方
- S7（可视化）
- S8（公式提炼）
- S9（模板生成）
- Q0（质量审计）

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 静默解决冲突 | 数据不一致 | 写入 conflicts，不自行选择 |
| 缺失值填 0 | 统计失真 | 保留为空 |
| 主键重复 | 数据膨胀 | 检测并标记 P0 |
| 派生字段计算错误 | 下游失真 | 可由原始字段重新计算 |
