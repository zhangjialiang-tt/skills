# S6 输出风险档案

## 高风险模式

### 1. 静默覆盖（概率：高）
- **症状**：跨 Skill 冲突时被静默解决
- **影响**：数据不一致，无法追溯
- **缓解**：写入 conflicts，不自行选择

### 2. 缺失值填 0（概率：中高）
- **症状**：空字段被错误填成 0
- **影响**：统计失真（如 emotion_score=0 被当作极低分）
- **缓解**：缺失值保留为空

### 3. 主键重复（概率：中）
- **症状**：同一章节出现多行
- **影响**：数据膨胀，统计错误
- **缓解**：检测并标记 P0

### 4. 派生字段错误（概率：低）
- **症状**：major_payoff_flag 计算错误
- **影响**：下游 S7/S8 失真
- **缓解**：派生字段可由原始字段重新计算

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 主键重复 | P0 | 拒绝输出 |
| 章节数与 S0 不一致 | P0 | 拒绝输出 |
| 数值越界（如 emotion_score=15） | P0 | 标记错误 |
| 缺失值被填 0 | P1 | 检查是否为真正的 0 |
| 跨 Skill 冲突未写入 conflicts | P0 | 拒绝输出 |
