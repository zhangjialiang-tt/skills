# S8 输出风险档案

## 高风险模式

### 1. 过度泛化（概率：高）
- **症状**：把单书观察伪装成整个题材的普遍规律
- **影响**：配方不可迁移
- **缓解**：每条配方必须引用具体章节证据，降低置信度

### 2. 专有名词复制（概率：中高）
- **症状**：配方中出现原作品的角色名、地名
- **影响**：配方不可复用
- **缓解**：抽象为变量（"主角""反派""资源"）

### 3. 剧情摘要（概率：中）
- **症状**：配方只是原剧情的缩写
- **影响**：无方法论价值
- **缓解**：必须抽象出底层机制和可替换变量

### 4. 缺乏反例（概率：中）
- **症状**：配方没有说明适用边界
- **影响**：被错误应用到不合适场景
- **缓解**：给出至少三条反例条件

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 配方中出现具体角色名/地名 | P0 | 替换为变量 |
| 配方无章节证据引用 | P1 | 补充证据 |
| 使用"所有网文""必须"等绝对化表述 | P0 | 改为"本作品""可以" |
| 缺少反例条件 | P1 | 补充至少 3 条 |
