# S8 题材套路公式提炼 — Skill IR

> Milestone 1 冻结：内部模块、不可外部路由；硬依赖 `[Q0]`，与 S7 可并行，输出可供 S9 类型专用模式消费。

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | S8 |
| 一句话功能 | 将单书结构数据压缩为可迁移的"题材配方" |
| 运行模式 | 单次执行（全书完成后） |
| 允许写入字段 | 不修改任何分析字段，只输出独立配方文件 |

## 触发条件

### 应触发
- "提炼公式"、"题材配方"、"套路总结"
- "可迁移模式"、"创作方法论"

### 不应触发
- 数据分析 → S6
- 可视化 → S7

## 输入依赖
- S6 master_table + book_statistics
- S1 volume_analysis
- S3 character_registry + relationship_events
- S4 payoff_events
- S5 commercial_patterns
- Q0 audit_summary

## 输出消费方
- 新书选题和大纲设计
- S9（生成定制分析模板）
- Skill 库题材参考资产

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 单书当普遍规律 | 配方不可迁移 | 降低置信度，标注来源 |
| 复制专有名词 | 配方不可复用 | 抽象为变量 |
| 只复述剧情 | 无方法论价值 | 必须抽象机制 |
