# S9 章节分析模板生成

根据题材配方和已验证字段，生成可批量复用的单章拆解表、填写说明和示例行。不重新分析原作品。

## 何时触发

- 基础版可在中央 Schema 冻结后运行
- 题材定制版在 S8 后运行
- 每次修改中央字段或评分体系后重新生成

## 执行

1. 读取 `references/prompt-template.md` 获取完整 Prompt 模板
2. 按模板生成字段字典和空白表头

## 模板必须包含

1. 基础索引
2. 结构功能
3. 因果与开放悬念
4. 人物与关系变化
5. 情绪、压力和释放评分
6. 压抑与爽点事件
7. 章末钩子和追读问题
8. 文本证据
9. 置信度和人工复核状态
10. 题材定制字段（不破坏通用核心字段）

## 下游交接

- 模板本身即交付物④
- `field_dictionary.json` → 所有 Skill 保持字段一致
- `blank_template.csv` → 新书分析项目
- `manual_review_view` → 创作者抽检

## 禁止事项

- 发明未被 Schema 验证的字段
- 把作品专有名词写入通用模板
- 删除通用核心字段
