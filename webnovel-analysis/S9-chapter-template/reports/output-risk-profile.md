# S9 输出风险档案

## 高风险模式

### 1. 字段膨胀（概率：高）
- **症状**：模板包含大量无法由 Skill 生成的字段
- **影响**：用户填写时无法对应到分析结果
- **缓解**：每个字段必须标注 owner_skill

### 2. 专有名词污染（概率：中）
- **症状**：通用模板中出现原作品的角色名
- **影响**：模板不可复用
- **缓解**：使用通用占位符

### 3. 核心字段缺失（概率：中）
- **症状**：证据与置信度字段被遗漏
- **影响：可追溯性丧失
- **缓解**：强制包含证据/置信度/复核字段

### 4. 题材字段污染通用表（概率：低）
- **症状**：genre-specific 模式删除了通用字段
- **影响**：下游 Skill 缺输入
- **缓解**：只扩展不删除

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 字段无 owner_skill | P1 | 补充来源 |
| 模板含具体角色名 | P0 | 替换为占位符 |
| 缺少 evidence/confidence 字段 | P0 | 强制添加 |
| genre-specific 删除了通用字段 | P0 | 恢复通用字段 |
