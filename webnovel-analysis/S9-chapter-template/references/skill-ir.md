# S9 章节分析模板生成 — Skill IR

> Milestone 1 冻结：内部模块、不可外部路由；通用模式硬依赖 `[Q0]`，类型专用模式硬依赖 `[Q0, S8]`。

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | S9 |
| 一句话功能 | 生成可批量复用的单章拆解表、填写说明和示例行 |
| 运行模式 | generic / genre-specific |
| 允许写入字段 | 不修改分析字段，只输出模板文件 |

## 触发条件

### 应触发
- "生成模板"、"分析表头"、"字段字典"
- "空白模板"、"章节分析表"

### 不应触发
- 数据分析 → S6
- 公式提炼 → S8

## 输入依赖
- 中央 Schema 字段定义
- S8 genre_formula（genre-specific 模式）
- Q0 确认的高质量示例

## 输出消费方
- 交付物④（模板本身）
- 所有 Skill（字段字典保持一致性）
- 新书分析项目（空白模板）

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 发明未验证字段 | 模板与 Skill 不匹配 | 仅基于 Schema 设计 |
| 专有名词写入通用模板 | 模板不可复用 | 使用通用占位符 |
| 删除通用核心字段 | 下游 Skill 缺输入 | 只扩展不删除 |
