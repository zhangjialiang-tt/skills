# S5 输出风险档案

## 高风险模式

### 1. 付费点误判（概率：高）
- **症状**：把"章节写得精彩"直接等同于"适合付费切分"
- **影响**：付费位置失真，真实转化率下降
- **缓解**：付费点前必须已交付一定阅读价值

### 2. 爽前卡滥用（概率：中高）
- **症状**：连续 3+ 章使用爽前卡
- **影响**：读者信任透支
- **缓解**：标记 hook_fairness="欺骗风险"

### 3. 追读问题泛化（概率：中）
- **症状**：follow_up_question 写成"接下来会发生什么"
- **影响**：S6 字段不可用
- **缓解**：禁止泛化，必须是具体可回答的问题

### 4. 强度与情绪混淆（概率：中）
- **症状**：emotion_score 高就自动判高 break_strength
- **影响**：断章驱动力失真
- **缓解**：break_strength 只看未完成刺激，不看情绪

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 连续3章 break_phase="爽前" | P1 | 标记欺骗风险 |
| follow_up_question 含"接下来" | P0 | 拒绝输出 |
| paywall_suitability="高" 但 value_delivered 为空 | P0 | 拒绝输出 |
| chapter_break_strength >= 9 但无明显钩子 | P1 | 人工检查 |
