# S5 商业卡点分析

识别章节的断章驱动力、付费切分价值、追读问题和连续阅读机制。分析的是文本如何驱动下一章阅读，不预测真实收入。

## 何时触发

- S0 文本完成后运行
- 推荐在 S1、S2、S4 完成后运行
- 两种模式：`incremental`（逐章）/ `consolidation`（全书汇总）

## 执行

1. 读取 `references/prompt-template.md` 获取完整 Prompt 模板
2. 读取 `../../schemas/enums.yaml` 获取枚举值
3. 按模板执行分析，输出标准信封格式

## 核心区分

| 概念 | 定义 |
|------|------|
| 章末钩子 | 本章结尾留下的具体未完成刺激 |
| 追读问题 | 读者看完后最想获得答案的问题 |
| 付费卡点 | 在读者已获得足够价值后，于高确定性期待形成处切断 |
| 纯打断 | 仅把完整场景从中间切开，却未形成新的阅读承诺 |
| 爽后卡 | 先兑现部分奖励，再打开更大问题 |
| 爽前卡 | 在即将兑现前切断，短期强但频繁使用容易透支信任 |

## 强度锚点速查

| 分数 | 含义 |
| ---: | ---- |
| 1-2 | 基本无继续动力 |
| 5-6 | 有明确问题，读者有继续意愿 |
| 9 | 高价值兑现临界点或重大反转后果未展开 |

## 防幻觉铁律

- 仅依据所给文本和结构化结果
- 不虚构平台规则、真实付费转化率或读者数据
- 不确定的付费位置标"存疑"
- 章节没有钩子时必须如实填写

## 下游交接

- 章节商业字段 → S6
- 高强度卡点 → S7 标记
- 付费点类型和兑现距离 → S8 商业配方
- 欺骗风险 → Q0

## 禁止事项

- 预测真实收入或订阅率
- 把"写得精彩"等同于"适合付费"
- 虚构平台运营规律
