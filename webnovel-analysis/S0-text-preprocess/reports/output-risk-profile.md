# S0 输出风险档案

## 高风险模式

### 1. 正文误删（概率：高）
- **症状**：广告删除时误删角色对话或场景描写
- **影响**：后续所有分析基于残缺文本
- **缓解**：删除前检查是否包含对话标记（引号、冒号）、场景分隔符

### 2. 章节边界错位（概率：中高）
- **症状**：把一个章节切成两章，或把两章合并
- **影响**：chapter_id 不稳定，跨章节分析全部错位
- **缓解**：无法确认时标记"存疑"，进入人工复核

### 3. 乱码无声处理（概率：中）
- **症状**：疑似乱码被直接删除
- **影响**：可能丢失关键信息
- **缓解**：疑似乱码必须保留原片段到 issues 中

### 4. 批次机械切分（概率：中）
- **症状**：严格按10章切分，把高潮兑现和前置压抑拆开
- **影响**：S4 爽点间隔统计失真
- **缓解**：优先保持事件完整性

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 清洗后字数减少 >30% | P0 | 人工检查删除内容 |
| 章节数与标题数偏差 >20% | P0 | 重新检查边界 |
| 同一文本出现在两个章节 | P0 | 标记重复 |
| 批次边界切在高潮章中间 | P1 | 调整批次边界 |
