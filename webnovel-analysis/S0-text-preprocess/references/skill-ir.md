# S0 文本预处理 — Skill IR

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | S0 |
| 一句话功能 | 将格式混乱的小说文本清洗、切章、编号并打包为稳定的分析批次 |
| 运行模式 | 单次执行 |
| 允许写入字段 | task_id, book_id, chapter_id, chapter_no, batch_id, word_count, boundary_confidence, text_status |

## 触发条件

### 应触发
- "预处理文本"、"清洗章节"、"切分批次"
- "标准化小说文本"、"去除广告"、"识别章节边界"

### 不应触发
- 结构分析 → S1
- 情绪评分 → S2
- 人物关系 → S3
- 任何涉及情节理解的任务

## 输入依赖
- O0 task_manifest
- 原始文本文件

## 输出消费方
- S1-S5（分析层输入）
- S6（中央表聚合）
- Q0（预处理问题）

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 广告误删正文 | 后续分析基于残缺文本 | 删除前检查是否包含对话/场景标记 |
| 章节边界识别错误 | 跨章节分析错位 | 标记"存疑"，进入人工复核 |
| 批次拆开完整事件 | 上下文断裂 | 优先保持事件完整性 |
| 乱码无声删除 | 信息丢失 | 疑似乱码必须保留到 issues |
