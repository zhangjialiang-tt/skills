# S7 输出风险档案

## 高风险模式

### 1. 缺失值画成 0（概率：高）
- **症状**：空字段在图表中显示为 0 分谷底
- **影响**：热力图出现虚假峰值/谷底
- **缓解**：缺失值不绘制，保持空白

### 2. 章节乱序（概率：中）
- **症状**：图表未按 chapter_no 排序
- **影响**：曲线走势失真
- **缓解**：强制按 chapter_no 排序

### 3. 字段混淆（概率：中）
- **症状**：爽点和情绪使用相同颜色
- **影响**：图表不可读
- **缓解**：爽点=橙色，情绪=绿/红，压力=深红

### 4. 过度美化（概率：低）
- **症状**：图表花哨但不支持决策
- **影响**：信息密度下降
- **缓解**：每图回答一个具体问题

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 缺失值画成 0 | P0 | 拒绝输出 |
| 章节未按 chapter_no 排序 | P0 | 重新排序 |
| 图表缺少评分范围标注 | P1 | 添加标注 |
| 单图超过 5 个指标 | P2 | 拆分为多图 |
