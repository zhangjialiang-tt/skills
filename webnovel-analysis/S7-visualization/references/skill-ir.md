# S7 可视化 — Skill IR

> Milestone 1 冻结：内部模块、不可外部路由；硬依赖 `[Q0]`，与 S8 可并行。本里程碑只定义可视化规格，不提供渲染完成证明。

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | S7 |
| 一句话功能 | 将中央表转化为热力图、情绪曲线、爽点时间线 |
| 运行模式 | excel / python / both |
| 允许写入字段 | 不修改原始分析，只生成图表 |

## 触发条件

### 应触发
- "可视化"、"热力图"、"节奏曲线"
- "爽点分布"、"数据图表"、"生成图表"

### 不应触发
- 数据分析 → S6
- 公式提炼 → S8

## 输入依赖
- S6 master_table

## 输出消费方
- 交付物②（热力图）
- Q0（异常章节）
- S8（卷级曲线特征）
- S9（典型高峰章节）

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 缺失值画成 0 | 假谷底 | 缺失值不绘制 |
| 修改中央表 | 原始数据被篡改 | 只读不改 |
| 虚构字段 | 图表失真 | 先检查列存在 |
| 图表过于复杂 | 不可读 | 每图回答一个问题 |
