# S4 输出风险档案

## 高风险模式

### 1. 爽点通胀（概率：高）
- **症状**：每章都被判定有爽点
- **影响**：爽点密度统计失真，S8 公式失效
- **缓解**：允许 payoff_present=false，一章可以没有爽点

### 2. 承诺当兑现（概率：中高）
- **症状**："主角即将反杀"被记为已兑现爽点
- **影响**：间隔统计失真
- **缓解**：未兑现的只能记为"爽点承诺"

### 3. 强度与压抑不匹配（概率：中）
- **症状**：suppression_level=1 但 payoff_strength=9
- **影响**：S7 热力图峰值失真
- **缓解**：高强度爽点必须有高前置压抑

### 4. 重复不标记（概率：中）
- **症状**：连续 3 次打脸不标记重复
- **影响**：套路化未被识别
- **缓解**：比较最近 5 次爽点类型

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| payoff_strength >= 8 且 suppression_level <= 1 | P0 | 人工检查 |
| payoff_present=true 且 reader_reward 为空 | P0 | 人工检查 |
| 连续3个主要爽点类型相同 | P2 | 重复风险 |
| 超过5章无正反馈 | P2 | 检查有意压抑 |
