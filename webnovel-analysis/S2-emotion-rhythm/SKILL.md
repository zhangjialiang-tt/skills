# S2 情绪节奏打分

把每章的压抑、释放和章末情绪状态量化为可跨章节比较的 1-10 分数据。评估的是目标读者的情绪体验，不是文学质量。

## 何时触发

- S0 后，可与 S1、S3、S4 并行
- 批次分析时必须读取相邻章节，避免孤立评分
- 全书完成后可再次运行 `calibration` 模式校准评分分布

## 执行

1. 读取 `references/prompt-template.md` 获取完整 Prompt 模板和评分锚点
2. 读取 `../../schemas/enums.yaml` 获取枚举值
3. 按模板执行评分，输出标准信封格式

## 评分锚点速查

| 分数 | emotion_score 含义 |
| ---: | --- |
| 1 | 极强压抑，几乎无希望 |
| 3 | 显著压抑，有行动空间 |
| 5 | 中性过渡 |
| 7 | 清晰爽感，阶段性成果 |
| 9 | 高潮级释放，长期积累兑现 |
| 10 | 全书罕见峰值，多线同时兑现 |

- `pressure_score`：1=无压力，10=极端压力
- `release_score`：0=无释放，10=充分兑现

## 防幻觉铁律

- 仅依据所给文本
- 不因出现争吵就自动判为高压
- 不因主角赢了一次对话就自动判为高爽
- 角色高兴不等于读者爽；必须说明读者得到何种情绪回报
- 不得用后续未知剧情反向合理化当前评分

## 下游交接

- 章节情绪字段 → S4 判断爽点释放
- `emotion_end` 和 `pressure_score` → S5 判断追读压力
- 批次统计 → S6
- 全书评分 → S7 热力图
- 峰谷分布 → S8 题材节奏公式

## 禁止事项

- 评价文学质量或个人喜好
- 用单一分数抹平复杂情绪走势
- 把角色情绪等同于读者体验
