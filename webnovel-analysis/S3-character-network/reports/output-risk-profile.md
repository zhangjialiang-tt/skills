# S3 输出风险档案

## 高风险模式

### 1. 角色膨胀（概率：高）
- **症状**：把"厂长""秘书"等职位称呼建成独立角色
- **影响**：角色表膨胀，关系网络失真
- **缓解**：建立 canonical_name + aliases 机制

### 2. 过度合并（概率：中）
- **症状**：同姓角色被错误合并
- **影响**：关系网络混乱
- **缓解**：不确定时保留独立实体，标"疑似同一人"

### 3. 推测当事实（概率：中）
- **症状**：把"他可能想陷害主角"写进 known_information
- **影响**：后续分析基于虚假前提
- **缓解**：严格区分 known/suspected/他人声称

### 4. 关系漂移（概率：低）
- **症状**：关系强度无缘无故改变
- **影响**：网络不连续
- **缓解**：必须有明确的 change_reason

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 单章新增角色 >5 个 | P1 | 检查是否为职位称呼 |
| known_information 包含"可能""也许" | P0 | 移至 suspected_information |
| 关系变化无 change_reason | P0 | 拒绝输出 |
| consolidation 后角色数 >50 | P2 | 检查合并质量 |
