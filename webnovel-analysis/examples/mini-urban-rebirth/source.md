# 第一章 被裁员的早晨

林川睁眼时，会议室墙上的电子钟正跳到九点零七分。窗外阴雨压着城南旧厂区，桌上那份解除劳动合同却亮得刺眼。他记得这个早晨：三年前，他被采购部经理周启明指控遗失原始账本，当众赶出公司。两周后仓库失火，所有能证明采购回扣的单据化成灰烬；半年后母亲病重，他因为没有收入错过手术窗口。如今同样的蓝色文件夹、同样不耐烦敲桌的手指，又一次出现在眼前。

他没有争辩，只借口去工位取私人物品。上一世他直到离职后才发现，昨晚自动备份的采购表里藏着三笔重复付款。这一次，他先拔下仍在运行的移动硬盘，又把邮件服务器中的发送记录导出到只读光盘。周启明派来的主管守在门口，催他十分钟内交出全部资料。林川故意打开空抽屉，让对方看到自己似乎毫无准备。

离开工位前，他把光盘塞进旧设备检修手册的夹层，又将一份无关紧要的复印件放进蓝色文件夹。手机同时弹出母亲的消息：晚上记得回家吃饭。林川握紧手机，确认这一世还有机会改变结局。门外脚步声停下，周启明亲自推开门，笑着说审计组已经到了。

林川跟着他穿过办公区，沿途看见几张熟悉又年轻的脸。上一世这些人后来有人离职，有人替周启明承担责任，也有人在火灾调查中保持沉默。他没有贸然提醒任何人，只在经过打印室时记下监控仍亮着绿灯。重生带来的并非全知，只是一次不能浪费的重新选择；每提前走一步，也可能让对手更早改变原来的计划。

# 第二章 原始账本

审计组临时占用了大会议室。周启明把蓝色文件夹推到桌子中央，声称林川在离职前擅自带走采购资料，可能给公司造成重大损失。几名同事低着头，没人愿意替一个即将离职的人说话。林川注意到财务主管陈岚也在场，她上一世曾私下提醒过他，却因为缺少原始凭证无法继续追查。

周启明要求立刻检查林川的背包和电脑。林川同意检查，却先让审计员记录文件夹封条编号。打开之后，里面只有公开版采购清单。周启明脸色一沉，追问真正的账本去了哪里。林川反问：既然经理确信存在另一份账本，是否说明他知道公开清单并非原始记录？会议室第一次安静下来，陈岚抬头看向周启明。

林川没有立即交出光盘，只展示邮件服务器导出的校验截图，证明三笔付款在同一分钟被重复审批。他提出由审计组封存服务器，并要求所有检查过程留下书面记录。周启明试图中止会议，却被审计负责人拒绝。就在局面开始倒向林川时，仓库管理员打来电话：存放纸质凭证的三号库房突然断电，监控也失去了信号。

审计负责人要求所有人留在会议室，陈岚则把刚才的问答逐句补进记录。林川注意到周启明反复查看一只没有来电的手机，像是在等某个迟到的信号。他想起上一世仓库失火前，公司外包电工曾突然请假。那个人的名字已经模糊，但工牌尾号似乎是零七。这个细节还不能成为证据，他把它写进自己的待核清单，没有当众说出。

# 第三章 第一次反制

周启明借口处理仓库故障起身离场，林川却当众提醒审计负责人，断电时间与重复付款调查开始时间重合。陈岚立刻联系安保部门封锁库房，审计组也派人同行。周启明被迫坐回原位，手指不断敲击桌面。他转而指控截图可以伪造，要求林川交出所有存储设备。

林川这才取出藏在检修手册里的只读光盘。光盘中不仅有原始采购表，还有昨晚服务器自动生成的签名文件。审计员现场核验后确认签名有效，三笔重复付款的最终审批账号都属于周启明。会议室里原本沉默的同事开始交换目光，陈岚正式申请暂停解除合同，并把林川列为内部调查证人。

这只是一次小反制。周启明虽然被暂时控制，却在离开会议室前低声告诉林川，重复付款只是别人故意留给他的线索，真正的账本从未进入公司服务器。几分钟后，林川收到陌生号码发来的照片：母亲正在菜市场买菜，身后站着一个戴黑帽的人。短信只有一句话——如果还想改变过去，今晚十点独自来旧仓库。

林川没有立即拨打母亲电话，那可能惊动跟踪者。他先给邻居发去一条普通的取快递消息，请对方顺路陪母亲回家，又把陌生短信和照片分别备份到两个账户。陈岚问他是否需要报警，他只说还缺少能够连接采购案与威胁者的证据。窗外雨势加重，三号库房方向却亮起了应急灯；那盏灯像一个倒计时，提醒他第一次胜利已经改变了后面的每一步。
