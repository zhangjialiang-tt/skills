# Q0 质量审计 — Skill IR

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | Q0 |
| 一句话功能 | 自动寻找格式错误、证据不足、跨 Skill 冲突、异常评分和疑似幻觉 |
| 运行模式 | batch / volume / book |
| 允许写入字段 | conflict_flag, manual_review_required, manual_review_status, reviewer_notes |

## 触发条件

### 应触发
- "审计"、"质量检查"、"数据校验"
- "冲突检测"、"异常扫描"、"检查分析质量"

### 不应触发
- 文学分析 → S1-S5
- 数据合并 → S6

## 输入依赖
- S6 master_table
- S0 chapter_index
- S3 relationship_events
- S4 payoff_events
- 原文（用于证据核查）

## 输出消费方
- 对应 Skill（P0 返回重跑）
- 人工抽检（P1 队列）
- S8（全局审计摘要）

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 静默修改原始结论 | 分析结果被篡改 | 只标记，不修改 |
| 把"可能有误"说成"确定错误" | 人工复核浪费 | 区分确定/推断/存疑 |
| 生成大量低风险问题 | 人工工作膨胀 | 合并相同根因，输出最小队列 |
