# Q0 输出风险档案

## 高风险模式

### 1. 越权修改（概率：高）
- **症状**：审计时直接修改了 S1-S5 的原始结论
- **影响**：分析结果被篡改，无法追溯
- **缓解**：只标记问题，不静默修改任何字段

### 2. 过度审计（概率：中）
- **症状**：生成大量 P2 低风险问题
- **影响**：人工复核工作膨胀
- **缓解**：合并相同根因，输出最小复核队列

### 3. 严重度误判（概率：中）
- **症状**：把格式问题标为 P0
- **影响**：阻塞分析流程
- **缓解**：P0 仅限主键重复、章节缺失、越界、明显幻觉

### 4. 证据不足当幻觉（概率：低）
- **症状**：把"可能有误"说成"确定错误"
- **影响**：人工复核方向错误
- **缓解**：区分确定错误/推断有误/存疑

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 审计修改了原始字段 | P0 | 拒绝输出 |
| P2 问题数 >10 | P1 | 合并相同根因 |
| 无问题但声称"绝对正确" | P2 | 添加有限性说明 |
| 最小复核队列 >5 章 | P2 | 优先选多风险章节 |
