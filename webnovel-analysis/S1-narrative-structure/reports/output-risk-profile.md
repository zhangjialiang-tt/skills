# S1 输出风险档案

## 高风险模式

### 1. 结构膨胀（概率：高）
- **症状**：每章被赋予 3-4 个"主功能"，单元边界模糊
- **影响**：S6 聚合时 chapter_function 字段冲突，S8 公式提炼失真
- **缓解**：强制"一个主功能 + 最多两个次功能"，单元必须有"目标建立—阻碍—结果"证据链

### 2. 卷幻觉（概率：中高）
- **症状**：只读前 10 章就断言"全书共 5 卷"
- **影响**：后续 S5/S8 基于错误的卷结构做判断
- **缓解**：incremental 模式下只提交卷候选，consolidation 模式才能确认

### 3. 伏笔误认（概率：中）
- **症状**：把普通描写标记为"伏笔"，后续分析围绕虚假伏笔展开
- **影响**：S5 追读问题失真，S8 配方包含虚假结构
- **缓解**：无回收证据前只能称"疑似伏笔"

### 4. 钩子泛化（概率：中）
- **症状**：章末钩子写成"让人想看下去"而非具体未完成刺激
- **影响**：S5 无法基于此判断付费卡点强度
- **缓解**：钩子必须是原文中的具体未完成动作/信息/危机

### 5. 事件≠功能混淆（概率：低）
- **症状**：把"主角被骗"作为功能，而非"制造误解"
- **影响**：不同章节的功能标签不一致，S8 无法提炼模式
- **缓解**：严格使用枚举值，事件是证据，功能是对叙事的抽象

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 单章 chapter_function 含逗号分隔的 3+ 项 | P1 | 人工复核 |
| incremental 模式下出现 volume_status="确认" | P0 | 拒绝输出 |
| 卷边界章节数 < 5 | P1 | 标记"存疑" |
| ending_hook 长度 < 10 字 | P2 | 提示泛化风险 |
| open_loop_closed 在原文无对应回答 | P0 | 标记冲突 |
