# O0 拆解任务编排器 — Skill IR

> Milestone 1 冻结：内部模块、不可外部路由；依赖 `[]`，输出由 S0 消费。本文后续“触发”均指根 Skill 的内部调度条件。

## 能力契约

| 字段 | 值 |
|------|------|
| 技能编号 | O0 |
| 一句话功能 | 将一本待拆解小说转化为可执行的批次计划、Skill 调用图、文件清单与验收标准 |
| 运行模式 | 单次执行 |
| 允许写入字段 | task_id, book_id, batch_id, execution_plan, file_manifest |

## 触发条件

### 应触发
- "开始拆解"、"分析这本书"、"创建拆解任务"
- "规划分析流程"、"拆解网文"、"网文分析"

### 不应触发
- 执行具体分析 → S0-S9
- 质量审计 → Q0

## 输入依赖
- 用户提供的图书信息和文件清单

## 输出消费方
- 所有 Skill（task_manifest）
- S0（file_manifest）
- Q0（review_policy）

## 失败模式

| 模式 | 后果 | 缓解 |
|------|------|------|
| 虚构章节数量 | 批次计划不可用 | 标记"存疑" |
| S5 放在 S1 之前 | 缺少输入数据 | 建立依赖图 |
| 无失败恢复机制 | 批次失败需从头来 | 设计检查点 |
