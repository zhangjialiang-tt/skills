# O0 输出风险档案

## 高风险模式

### 1. 虚构章节数（概率：高）
- **症状**：用户未提供章节数时，O0 假设"共 200 章"
- **影响**：批次计划不可用
- **缓解**：标记"存疑"，等 S0 确认

### 2. 依赖顺序错误（概率：中）
- **症状**：S5 被放在 S1/S2/S4 之前
- **影响**：S5 缺少输入数据
- **缓解**：建立 Skill 依赖图，强制顺序

### 3. 无恢复机制（概率：中）
- **症状**：批次失败后需要从头重新运行
- **影响**：时间浪费
- **缓解**：设计检查点，支持从最近完成批次恢复

### 4. 机械切分（概率：低）
- **症状**：严格按 10 章切分，不考虑事件完整性
- **影响**：分析上下文断裂
- **缓解**：优先保持事件完整性

## 检测规则

| 条件 | 风险等级 | 触发动作 |
|------|----------|----------|
| 出现具体章节数但用户未提供 | P0 | 改为"存疑" |
| S5 在 S1 之前 | P0 | 调整顺序 |
| 无 checkpoint_policy | P1 | 添加检查点 |
| 要求人工逐章审核 | P1 | 改为 20% 抽样 |
