# 爽点与情绪层（网文核心！）

> 网文的本质是情绪商品。这一层的分析权重在整个拆书中应该是最高的。

## 分析目标

评估作品的情绪供给能力和读者爽感体验。

## 分析框架

### 1. 核心爽点

- 主爽点类型识别（可多选）：
  - [ ] 打脸：主角被低估后逆袭证明自己
  - [ ] 装逼：主角展示碾压级实力/知识/财富
  - [ ] 升级：实力/等级/地位的提升
  - [ ] 获宝：获得稀有物品/能力/机缘
  - [ ] 复仇：以牙还牙的报复快感
  - [ ] 逆袭：从底层到巅峰的阶级跨越
  - [ ] 收后宫：感情征服
  - [ ] 智斗：智商碾压对手
  - [ ] 经营：建设势力/领地/商业帝国
  - [ ] 揭秘：世界观/身世之谜的揭示
  - [ ] 其他：___
- 爽点组合：多个爽点如何交织？是否有层次感？
- 爽点纯度：是否有杂质干扰？（如不必要的虐主、无意义的压抑）

### 2. 爽点频率

- 统计方法：在阅读范围内抽样统计爽点触发次数
- 频次评估：
  - 小爽点（一句话/一段话的爽）：每 X 章一次
  - 中爽点（一个场景的爽）：每 X 章一次
  - 大爽点（整个副本/剧情线的高潮）：每 X 章一次
- 间隔容忍度：读者能接受的最长平淡期是多少章？本作是否超出？

### 3. 情绪曲线

- 整体走势：起-伏-起-伏-起（标准）？持续走高？持续走低？波动过大？
- 高潮分布：高潮点是否均匀分布？是否有高潮集中后长期低迷？
- 低谷处理：压抑段是否过于漫长？是否有"虐"过头导致弃书的风险？
- 过渡段质量：平淡过渡段是否仍然有趣？

### 4. 期待感管理

- 期待制造方式：
  - [ ] 实力预期：暗示主角未来能达到的高度
  - [ ] 宝物预期：暗示即将获得的强大能力/物品
  - [ ] 冲突预期：暗示即将发生的对决/打脸
  - [ ] 揭秘预期：暗示即将揭开的秘密
  - [ ] 关系预期：暗示感情线的发展
- 期待-满足循环：每个被制造的期待是否在合理篇幅内被满足？
- 期待透支：是否存在期待制造了但一直不满足的情况？

### 5. 压抑与释放

> 这是网文爽感的底层机制：先压抑（制造情绪压力），再释放（爽点爆发）

- 压抑设计：
  - 压抑来源：反派欺压/实力不足/身份隐藏/误解/环境限制
  - 压抑程度：是否合适？（太轻没感觉，太重导致弃书）
  - 压抑时长：从压抑到释放的间隔章数
- 释放质量：
  - 释放力度：是否与压抑程度匹配？"打回去"是否够狠？
  - 释放方式：直接打脸/间接碾压/公开打脸/私下解决
  - 释放的"爽度"评分：1-10

### 6. 情绪多样性

- 情绪类型覆盖：
  - [ ] 爽/燃：热血沸腾的胜利时刻
  - [ ] 笑：幽默桥段、吐槽、反差萌
  - [ ] 泪：感人场景、牺牲、离别
  - [ ] 惊：反转、悬疑、恐怖
  - [ ] 甜：感情线的甜蜜时刻
- 情绪切换：不同类型情绪切换是否自然？是否有情绪单调问题？
- 情绪记忆点：是否有让人印象特别深刻的情绪场景？
