# 剧情结构层

## 分析目标

评估故事结构的完整性、节奏感和叙事技巧。

## 分析框架

### 1. 主线脉络

- 核心故事线：一句话概括主线剧情
- 终极目标：主角追求的最终目标是否明确？
- 阶段性目标：各阶段的小目标是否清晰？
- 主线偏离：是否存在无关支线干扰主线推进？

### 2. 故事单元

- 单元划分：按副本/事件/场景将故事切分为独立单元
- 每个单元的起承转合：是否有完整的叙事弧？
  - 起因（setup）
  - 发展（confrontation）
  - 高潮（climax）
  - 收束（resolution）
- 单元之间衔接：过渡是否自然？是否有承上启下？

### 3. 开篇设计（重点关注）

- 黄金三章：前三章是否完成以下任务？
  - [ ] 建立主角人设和处境
  - [ ] 展示核心冲突或悬念
  - [ ] 暗示世界观特色
  - [ ] 制造追读钩子
- 切入点：故事从哪个时间点切入？是否是最佳切入点？
- 信息量：开篇信息密度是否合适？（信息过载 vs 信息不足）
- 开篇评级：S/A/B/C

### 4. 伏笔管理

- 已识别的伏笔：列出主要伏笔及埋设位置
- 伏笔回收：是否已回收？回收是否巧妙？是否有"伏笔忘了收"？
- 伏笔层次：短期伏笔（几章内回收）/中期伏笔（一卷内）/长期伏笔（跨卷）
- 伏笔密度：是否合适？（太少导致平淡，太多导致混乱）

### 5. 转折设计

- 关键转折点：列出 3-5 个最重要的剧情转折
- 转折质量：是否意料之外、情理之中？
- 铺垫充分度：转折前是否有足够的线索和铺垫？
- 转折频率：是否过于频繁导致疲劳？或太少导致平淡？

### 6. 悬念管理

- 章节级悬念：章末 hook 是否吸引人？
- 卷级悬念：每卷结尾是否留下足够大的悬念？
- 全书级悬念：贯穿全文的核心谜题是否存在？
- 解谜节奏：悬念的提出和解开节奏是否合理？
