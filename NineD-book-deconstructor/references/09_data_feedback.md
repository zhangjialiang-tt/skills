# 数据与反馈层

## 分析目标

基于可获取的数据和读者反馈，从量化角度佐证或修正文本分析结论。

> 本维度是"可选的"。如果用户没有提供数据（收藏、月票、评论等），则标注"数据缺失"，
> 仅进行基于文本的推断，且必须明确标注为推断。

## 分析框架

### 1. 数据表现（需用户提供数据）

- 可分析的数据维度：
  - 收藏/追读/书架数据及趋势
  - 月票/推荐票/打赏数据
  - 在读/完读数据
  - 评分/评分分布
  - 章节级别的阅读完成率
- 趋势分析：
  - 整体走势：上升/下降/稳定/波动
  - 关键节点：数据暴涨/暴跌的时间点及对应剧情
- 数据与文本分析的交叉验证：
  - 你觉得写得好的章节，数据是否好？
  - 你觉得写得差的章节，数据是否差？
  - 如有偏差，可能的原因是什么？

### 2. 读者评论分析（需用户提供或可公开获取）

- 高频关键词：读者评论中最常出现的词是什么？
- 正面反馈集中点：读者在夸什么？
- 负面反馈集中点：读者在吐槽什么？
- 催更内容：读者在催什么？（催剧情推进？催感情线？催打脸？）
- 争议话题：读者之间存在什么争议？
- 粉丝创作：是否有同人/分析贴/梗图等 UGC？

### 3. 高光章节分析

- 数据高光章节：哪些章节数据表现最好？
- 高光原因推测与验证：
  - [ ] 重大爽点释放
  - [ ] 重要剧情转折
  - [ ] 感情线推进
  - [ ] 世界观揭秘
  - [ ] 外部推荐/引流
- 高光章节的复现性：这种高光能否在后文中复现？

### 4. 低谷分析

- 数据低谷章节：哪些章节数据明显下滑？
- 低谷原因推测与验证：
  - [ ] 剧情节奏拖沓
  - [ ] 换地图/新篇章适应期
  - [ ] 压抑段过长
  - [ ] 感情线崩坏
  - [ ] 断更/更新不稳定
  - [ ] 外部竞品冲击
- 恢复策略：数据如何恢复？恢复速度如何？
