# 读者心理层

## 分析目标

从读者体验视角评估作品的代入感、认同感和持续阅读动力。

> 这一维度要求你代入读者角色，以"真实读者的阅读体验"为标准进行判断，而非以评论家视角。

## 分析框架

### 1. 代入感

- 代入机制：
  - [ ] 身份代入：读者能在现实中找到与主角的相似点
  - [ ] 处境代入：主角面临的困境让读者感同身受
  - [ ] 欲望代入：主角追求的正是读者渴望的
  - [ ] 能力代入：主角的能力让读者产生"如果我也能这样"的幻想
  - [ ] 情绪代入：主角的情绪反应符合读者的本能反应
- 代入障碍：
  - 主角是否有让人难以认同的行为或价值观？
  - 主角的起点是否离读者太远（过于天才/过于废柴）？
  - 是否有过多的上帝视角打断代入感？
- 代入感持续性：随着剧情推进，代入感是增强还是减弱？

### 2. 认同感

- 价值观认同：主角的行为准则和道德观是否被读者认可？
  - 双标检测：主角是否对自己一套标准、对别人另一套？
  - 圣母/冷血检测：主角是否过度圣母或过度冷血？
- 选择认同：主角面对关键选择时的决定，读者是否认同？
- 成长认同：主角的成长路径是否被读者认可？（太快=开挂不合理，太慢=窝囊）
- 认同危机点：找出读者可能"出戏"、"反感"的具体段落

### 3. 社交货币

> "社交货币"指读者愿意讨论、分享、安利作品的动力

- 名场面：是否有值得截图/引用的经典场景？
- 金句：是否有出圈的台词或段落？
- 话题性：是否有能引发讨论的设定或剧情？
  - 战力讨论？CP 站队？剧情预测？设定辩论？
- 安利潜力：读者向朋友推荐时的一句话卖点是什么？

### 4. 弃书风险

- 高风险段落识别：
  - [ ] 开篇劝退：前三章信息过载/节奏过慢/人设不讨喜
  - [ ] 中期疲劳：剧情重复/节奏拖沓/爽点密度下降
  - [ ] 换地图崩坏：进入新篇章时设定逻辑断裂
  - [ ] 战力崩坏：力量体系失衡导致前期积累白费
  - [ ] 感情线崩坏：CP 强行拆散/感情发展不合理
  - [ ] 断更后回坑难：断更位置不友好
- 弃书率估算：如果这是付费阅读，你会在哪个节点弃书？
- 挽回机制：是否有设计"回坑钩子"？

### 5. 追读动力

- 核心追读动力排序：（从强到弱排列）
  1. 想知道接下来发生什么（悬念驱动）
  2. 想看主角变强（成长驱动）
  3. 想看下一个爽点（情绪驱动）
  4. 想看到某个角色的结局（角色驱动）
  5. 习惯性追读（惯性驱动）
  6. 世界观吸引（设定驱动）
- 动力持续性：追读动力是否有衰减？
- 动力多样性：如果某个动力减弱，是否有其他动力接棒？
