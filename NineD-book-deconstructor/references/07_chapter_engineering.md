# 章节工程层

## 分析目标

从"网文生产流水线"角度评估作品的章节设计、更新策略和结构工程。

> 网文是日更连载的特殊文体。章节工程层关注的是"作为连载产品的设计"，而非文学作品的传统结构。

## 分析框架

### 1. 单章结构

- 章均字数：统计平均值
  - 起点标准：2000-3000 字/章
  - 番茄标准：1500-2500 字/章
  - 飞卢标准：1500-2000 字/章
- 单章叙事完整性：每章是否有独立的小剧情闭环？
  - [ ] 有开头（承接上章）
  - [ ] 有发展（本章核心内容）
  - [ ] 有转折或推进
  - [ ] 有结尾（引出下章）
- 单章信息量：每章读者获得了什么？新信息/情绪/悬念？

### 2. 章末钩子（Cliffhanger）

> 章末钩子是网文追读率的关键驱动因素。

- 钩子类型：
  - [ ] 悬念钩子："就在这时，门突然开了..."
  - [ ] 打脸预告："明天，他会让所有人闭嘴"
  - [ ] 揭秘预告："他终于知道了那个秘密"
  - [ ] 危机钩子：主角陷入危险
  - [ ] 装逼预告：即将展示实力
  - [ ] 感情钩子：感情线推进
  - [ ] 其他：___
- 钩子频率：有钩子的章节占比？X/总章数
- 钩子质量：是否真正让人想点下一章？还是套路化敷衍？
- 钩子回收：钩子制造的期待是否在下一章被满足？

### 3. 卷/篇划分

- 分卷方式：作者是否显式分卷？
- 每卷结构：
  - 卷开局：是否重新建立本章的悬念和方向？
  - 卷中发展：剧情推进节奏
  - 卷末高潮：是否有令人满意的卷终高潮？
  - 卷间过渡：上一卷结束和下一卷开始如何衔接？
- 卷的完整性：每卷是否构成一个相对完整的故事单元？

### 4. 更新节奏（如果有更新数据）

- 日更字数：xxx 字/天
- 更新频率：日更/隔日更/周更/不定
- 爆更策略：是否有集中爆更？爆更章节的内容密度如何？
- 断更分析：如有断更，断在什么剧情点？对读者体验的影响？

### 5. 总体字数与节奏

- 全书预计字数：（如有完本计划）
- 当前进度：（已写/计划）
- 字数效率：剧情推进速度与字数的比值是否合理？
  - "水字数"检测：
    - [ ] 大量无意义描写
    - [ ] 重复性内心独白
    - [ ] 套路化打斗循环
    - [ ] 无推进的对话
    - [ ] 设定反复说明
- 节奏健康度：是否有明显的"拖"或"赶"？
