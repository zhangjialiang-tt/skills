# 文笔与叙事层

## 分析目标

评估作品的语言表达质量、叙事技巧和信息传递效率。

## 分析框架

### 1. 叙事视角

- 人称：第一人称/第三人称有限/第三人称全知/多视角切换
- 视角一致性：是否存在无故的视角跳跃（head-hopping）？
- 视角效果：选择的视角是否适合这个故事的讲述？
- PS：第一人称自带沉浸感优势，但限制了信息展示；第三人称更灵活但需要更强的笔力维持代入感

### 2. 语言风格

- 风格标签（可多选）：轻松/严肃/幽默/热血/文艺/朴实/中二/诗意/口语化
- 辨识度：换个作者写同样的情节，读者能否分辨出差异？
- 风格一致性：风格是否统一？还是忽而严肃忽而搞笑？
- 适配度：语言风格与题材/世界观是否匹配？
  - 例：玄幻用口语化吐槽风格 → 正常
  - 例：严肃历史用大量网络梗 → 违和

### 3. 信息传递

- 设定说明方式：
  - [ ] 融入剧情（推荐）：通过角色的经历和对话自然展现
  - [ ] 角色科普：通过导师讲解/角色对话说明
  - [ ] 旁白说明：叙述者直接大段解释
  - [ ] 系统面板：通过系统/面板展示
- 说明文检测：是否有大段纯说明性的段落？（超过 300 字的连续说明即为"说明文"）
- 信息密度：读者获取信息的节奏是否舒适？

### 4. 对话质量

- 自然度：对话是否符合人物性格和身份？
- 功能性：对话是否推进剧情或展示人物？还是纯水？
- 辨识度：不看对话标记（xx说），能否通过说话方式分辨不同角色？
- 废对话识别：是否有大段无信息量的寒暄/废话？
- 金句检测：是否有令人印象深刻的台词？

### 5. 描写能力

- 场景描写：环境/氛围描写的画面感如何？
- 战斗描写：动作是否清晰？节奏是否紧凑？是否有画面感？
- 心理描写：内心活动的深度和自然度？
- 留白技巧：是否知道什么时候不写？（过度描写 vs 描写不足）
- 感官覆盖：是否调动了多种感官？（视觉/听觉/触觉/嗅觉/味觉）

### 6. 节奏把控

- 详略判断：
  - 哪些段落详细描写（合理）？
  - 哪些段落简略带过（合理）？
  - 哪些段落明显拖沓/水字数？
- 过渡段：场景切换是否流畅？
- 加速/减速：高潮段落是否加速？日常段落是否减速？节奏变化是否服务于情绪？
