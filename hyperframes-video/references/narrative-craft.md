# 叙事工艺（narrative-craft）

> 出处：hyperframes-agent-video 项目 script.md / script_review.md 实战（2026-10-29/30，
> 90s 成片语速 4.1 字/秒、全片无空泛口号）。语速预算表方法见 `content-method.md` §1，
> 事实核查规则见 §2；本文件只补“决定旁白质感”的工艺项。

## 1. 前 5 秒钩子（不放口号）

- 形式：问句 / 冲突 / 反差——直接建立“认知缺口”，让观众为答案留下来；
- 实例（已验证）：“如果 AI Agent 能写 HTML，它能否直接写出一段视频？”——两个具体名词
  （AI Agent / HTML）+ 一个不可能感（写 HTML → 视频）；
- 反例：”引领未来、重新定义、极致体验“类口号——零信息量，且与画面互相稀释；
- 钩子句上屏时机：打字机/逐字浮现 0.3s 起，5s 内完成并让位给主字标（见 `assets/examples/ex01-hook.html`）；
- 钩子句的语速可以刻意慢（如 3.7 字/秒）——留悬念比填满重要。

## 2. 句子节奏

- 全片语速目标 4.0–4.5 字/秒；单句超 4.8 即为全片最快句，分镜里给该场景动画提前 0.5s 起
  （避免“话等画”）；
- 短句优先：能两段说清的不用一个长句——旁白是”说出来的“，从句套从句必糊；
- 每句只推进一个认知（一个新信息或一个转折）；删掉不推进认知的字；
- 英文术语按 2 字/词折算占时；混读句留实测校准余量（见 §4）。

## 3. 文案删减纪律（评审阶段逐条过）

1. **删虚词收短**：”而这一切，其实都可以用代码来描述“ → 删”来描述“前的冗余，能短则短；
2. **删语义重复**：同一信息在两个分句出现两次，删后一个（实例：”动画是可寻址的“从句
   与”渲染器可以精确跳到任何一帧“重复，删前者）；
3. **删推测性措辞**：”即将支持 / 未来会有“类表述不进脚本（同时是事实核查红线）；
4. 场景内大字与字幕**不同文**——画面字承担的信息，对应字幕条目隐藏（SRT 保留），
   同屏重复是最常见的廉价感来源。

## 4. TTS 发音风险（配音阶段实测项）

- **英文混读**：如“AI Agent”——本地 Kokoro 对英文混读发音不稳定，音频阶段必须试听；
  不可接受时替换为中文等价词（“AI 助手”），脚本同步改；
- **数字与单位**：逐位/自然读法不确定时改写为文字或拆分句子，不要赌；
- 速度系数：基准 1.22（≈4.5 字/秒），超窗段 1.28–1.32 提速，**相邻段系数差 ≤6%**（听感连贯）；
  个别句需要 >1.35 才能装下时，改脚本而不是硬提速；
- 音量核验：max ≈ −3dB 无削波；各段 mean 电平差 <2dB（成片端证据见 qc_sample.py 的 max_db）。

## 5. 脚本评审表范例（冻结前逐场过，可直接抄格式）

| 场景 | 时长 | 字数 | 语速（字/秒） | 判定 |
|---|---|---|---|---|
| S01 | 7s | 26 | 3.7 | 稍慢，刻意留悬念，可接受 |
| S02 | 9s | 43 | 4.8 | 偏快，画面为流程动画可承接 |
| S08 | 8s | 39 | 4.9 | 全片最快，已安排提前 0.5s 起 |

评审输出三件套：**节奏表**（上表）+ **修改记录**（删了哪句哪词、为什么）+ **遗留风险**
（如“英文混读待音频阶段实测”）。评审通过才冻结；冻结后改动须同步 storyboard 与字幕。

## 6. 收束句

- 结尾用三个可验证关键词收束（实例：”可编程 / 可复现 / 可版本管理“）——每个词都是
  前面场景证明过的，不是新口号；
- 落版元素：品牌字标 + 项目地址/官网；收束句语速回到舒适区，给最后 1s 呼吸。
