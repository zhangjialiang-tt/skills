# 项目简报模板（阶段 1 产物）

```yaml
# 作品假设
platform: 番茄
genre: 末日基地建设
target_readers: 喜欢生存、经营、团队成长的男性读者
core_experience: 看主角用工程和组织能力把混乱变成秩序
target_chapters: 300
chapter_words: 2500
ending_known: true

# 作者约束
excluded_directions:
  - 不写后宫
  - 不写无脑碾压

# 素材来源
reference_materials:
  - 类型：现实参考
    描述：土木工程、应急管理相关资料
```

## 填写说明

- `platform`：目标发布平台（番茄/起点/晋江/其他）
- `genre`：题材类型
- `target_readers`：用一句话描述目标读者画像
- `core_experience`：读者获得的核心体验（必须具体，不是"好看"）
- `target_chapters`：预计总章数
- `chapter_words`：每章目标字数
- `ending_known`：是否已确定结局（true/false）
- `excluded_directions`：作者明确不接受的方向
- `reference_materials`：现实资料和专业素材来源
