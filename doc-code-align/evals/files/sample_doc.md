# 缓冲聚合模块（sample_module）接口契约

## 概述

sample_module 完成输入字节流的聚合缓冲与转发，供上游帧组包模块使用。

## 参数

| 参数 | 值 | 说明 |
|---|---|---|
| `DEPTH` | 8 | 聚合深度（字节），契约要求 ≥8，实现取最小值 |
| `RESET_WAIT` | 8 | 复位后稳定等待拍数 |

## 状态机

三状态轮转：`S0`（等待）→ `S1`（运行）→ `S2`（完成）→ 回 `S0`。

## 数据通路

输入字节从移位寄存器**高位移入**，低字节侧先出。

## 控制信号

- `flush`：流刷新，待实现（计划 2026-Q4 随停流特性引入）。

## 内部状态输出

| 名称 | 类型 | 说明 |
|---|---|---|
| `agg_q` | `logic[127:0]` | 聚合缓冲 |
| `st_q` | `state_t` | 当前状态 M_IDLE | M_RUN | M_DONE |

## 活性保护

`STALL_WARN_CYCLES = 128`：状态停滞超过该阈值触发告警。
