# L0–L3 修复阶梯与复验要求

> 传播路径：修复只沿 L0→L3 阶梯进行，每档通过后才能进下一档。

## L0 奴约注释（comments-only）

- 只补注释，不动任何逻辑；verdict: comments-only。
- 优先补 implicit 项（源码可答但没写）。
- 注释写"why"不写"what"；引用行号锚定。
- 完成后必须复跑测卷（check）确认 implicit → answered 转化。

## L1 测卷复测

- 复跑 `readability_model.py check`，测卷得分提升量与三态转化数记入报告。
- 得分不升反降时停止，回到 L0 审视注释质量。

## L2 结构调整（用户确认后）

- 拆模块、调接口、改时序语义表述——每次一个聚焦改动。
- 修改前后各跑一次审计（findings JSON 前后对比），单变量归因。

## L3 重命名（跨文件传播，用户逐项确认）

- 信号/模块重命名涉及跨文件传播，必须用户逐项确认后执行。
- 改名执行顺序：声明 → 实例化点 → 文档引用，顺序执行避免中间态。
