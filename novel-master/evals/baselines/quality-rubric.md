# novel-master v1.2.0 — 质量基线评分 Rubric

> 阶段 0：建立并冻结
> 评分尺度：1～5 分（5=优秀，1=不可用）
> **本 Rubric 在生成 v1.2-rc1 输出前冻结，不根据 v1.2 结果调整。**

---

## 评分维度

### D1. Promise 具体性（1～5）

| 分数 | 标准 |
| --- | --- |
| 5 | promise 精准描述本章向读者承诺的具体内容，可直接验证 |
| 4 | promise 具体但有一处不够精确 |
| 3 | promise 模糊但可推断（如"推进剧情"） |
| 2 | promise 过于空泛，无法验证 |
| 1 | 无 promise 或完全无意义 |

### D2. Payoff 质量（1～5）

| 分数 | 标准 |
| --- | --- |
| 5 | 所有承诺兑现在本章确实发生，有具体文本证据 |
| 4 | 主要兑现发生，一处次要目标未完全兑现 |
| 3 | 兑现部分发生但关键目标被延后 |
| 2 | 承诺的目标基本未兑现 |
| 1 | 承诺和正文完全脱节 |

### D3. 阅读动力（1～5）

| 分数 | 标准 |
| --- | --- |
| 5 | 章末有自然的继续阅读动力（目标未完成/新悬念/情感牵引），非机械断章 |
| 4 | 有继续阅读动力但略生硬 |
| 3 | 动力存在但较弱（如仅靠"下章将揭示"） |
| 2 | 章末无明确继续动力 |
| 1 | 章末平淡到无阅读欲望 |

### D4. 风格自然度（1～5）

| 分数 | 标准 |
| --- | --- |
| 5 | 叙事流畅自然，无 AI 腔痕迹，句式有变化 |
| 4 | 基本自然，1～2 处轻微 AI 腔 |
| 3 | 可读但 AI 腔明显（如过多排比、空洞总结句） |
| 2 | AI 腔严重影响阅读体验 |
| 1 | 机械式输出，失去小说质感 |

### D5. 模板化程度（1～5，越高越好=自然，越低=机械）

| 分数 | 标准 |
| --- | --- |
| 5 | 本章写作方式与前后章保持多样性，无机械复制感 |
| 4 | 基本多样，一处场景模式与其它章相似 |
| 3 | 出现模板化但不影响阅读（如类似的章末句） |
| 2 | 明显模板化（如每章相同段落结构、相同结尾模式） |
| 1 | 高度模具化，每章几乎只有细节差异 |

### D6. Reviewer 证据充分性（1～5）

| 分数 | 标准 |
| --- | --- |
| 5 | 每条诊断附具体文本证据，可直接验证 |
| 4 | 大部分诊断有证据，个别只有概括性意见 |
| 3 | 证据和概括性意见各半 |
| 2 | 大部分是概括性意见，只有零星证据 |
| 1 | 完全没有文本证据，全是空泛评价 |

---

## Rubric 使用规则

1. 每份输出由 Judge 独立评分 6 个维度。
2. 总分 = 各维度分数之和（范围 6～30）。
3. 调优集 7 个任务，每任务 v1.1 生成 2 份 → 14 份评分。
4. Rubric 冻结后不因 v1.2 输出表现而调整任何标准或权重。
