# style-guide-template.md

> 用途：项目 style_guide.md 的标准模板。用户创建新项目时基于此模板填写，chapter-writer 和 novel-reviewer 以此为风格约束。
> 引用方式：novel-brief 初始化时生成；chapter-writer 写作时 `include: style_guide.md`。
> 说明：`{{占位符}}` 为用户需填写部分，不得固化某一题材的风格。

## 模板

```markdown
# 风格指南

## 1. 叙事视角

- 主视角：{{第一人称 / 第三人称有限 / 第三人称全知 / 多视角轮换}}
- 视角人物：{{主角名 / 轮换规则}}
- 视角切换规则：{{按章节切换 / 按场景切换 / 不切换}}
- 视角限制：{{视角人物不可知的信息不得出现 / 允许全知叙述者插话}}

## 2. 叙事距离

- 默认距离：{{近距离（内心独白式）/ 中距离（跟随但不深入）/ 远距离（旁观叙述）}}
- 距离变化规则：{{高潮时拉近 / 过渡时拉远 / 保持恒定}}
- 禁止：{{突然从近距离跳到全知 / 在紧张场景中拉远}}

## 3. 句式节奏

- 默认句长：{{短句为主（10字内）/ 中长句为主（15-30字）/ 混合}}
- 节奏模式：{{动作场景用短句加速 / 描写场景用长句减速 / 对话与叙述交替}}
- 段落长度：{{每段不超过N句 / 按自然节奏分段}}
- 禁止：{{连续N段相同句式 / 所有段落等长}}

## 4. 描写密度

- 动作场景：{{高密度感官细节 / 简洁动作为主}}
- 过渡场景：{{略写 / 适度环境描写}}
- 情感场景：{{内心描写为主 / 外在表现为主 / 两者结合}}
- 环境描写：{{每场景开头建立 / 融入动作中 / 极少描写}}
- 禁止：{{大段静态描写中断叙事 / 每个场景都详细描写环境}}

## 5. 对话规则

- 对话占比：{{约N% / 视场景而定}}
- 对话标签：{{"说"为主 / 多样化动词 / 尽量省略标签}}
- 潜台词：{{角色经常言不由衷 / 角色直抒胸臆 / 视角色而定}}
- 对话节奏：{{短促交锋 / 长段独白 / 混合}}
- 禁止：{{所有角色说话方式相同 / 对话中灌输背景信息（"你知道吗"综合症）}}

## 6. 角色声音

- 主角语言特征：{{口头禅 / 用词习惯 / 语气特点}}
- 配角区分规则：{{每个重要角色至少一个语言标识}}
- 叙述者声音：{{冷静客观 / 带幽默感 / 带情感倾向}}
- 禁止：{{模仿特定在世作者的可识别文风}}

## 7. 信息说明策略

- 背景信息：{{融入剧情自然揭示 / 开头集中交代 / 角色对话中透露}}
- 力量体系说明：{{通过角色体验展示 / 简短旁白说明 / 不解释只展示}}
- 前情回顾：{{每章开头简短回顾 / 不回顾 / 通过角色记忆自然带出}}
- 禁止：{{大段百科式说明中断叙事 / 角色向已知信息的对象解释}}

## 8. 章节目标字数

- 标准章节：{{N字（如3000-4000字）}}
- 允许浮动：{{±N字}}
- 高潮章节：{{可延长至N字}}
- 过渡章节：{{可缩短至N字}}

## 9. Hook 原则

- 章首 Hook：{{悬念 / 冲突 / 异常 / 情感冲击 / 不强制}}
- 章尾 Hook：{{悬念断章 / 情感余韵 / 转折预告 / 不强制}}
- 禁止：{{每章都用相同 Hook 模式 / 为断章而断章（无因果的机械悬念）}}
- 断章规则：{{在冲突升级时断 / 在信息揭示前断 / 在情感高点断}}

## 10. 回顾策略

- 读者已知信息：{{不重复 / 换角度重提 / 通过新角色视角重述}}
- 重要伏笔提醒：{{通过角色行为自然带出 / 不主动提醒}}
- 前章结尾衔接：{{直接续接 / 时间跳跃后简述 / 换视角重新开始}}

## 11. 常见 AI 腔规避项

以下表达模式禁止或严格限制使用：

- 禁止：空洞总结句（"这一切才刚刚开始"、"故事还在继续"）
- 禁止：过度使用"仿佛"、"宛如"等比喻连接词（每千字不超过N次）
- 禁止：角色突然进行哲学独白（除非角色设定如此）
- 禁止：所有冲突都通过对话解决
- 禁止：情感表达只用"心中一紧"、"瞳孔微缩"等套路
- 禁止：段落结尾总是升华或感悟
- 禁止：连续使用三个以上排比句
- 限制：形容词堆砌（每个名词前最多一个形容词）
- 限制：被动语态使用频率
- 限制：感叹号使用频率（每章不超过N个）
- 要求：感官描写至少覆盖两种以上感官（不只视觉）
- 要求：情绪通过行为和细节传达，而非直接陈述

## 12. 题材特殊规则（可选）

{{用户根据具体题材补充，如：
- 玄幻：战斗描写规则、境界突破描写方式
- 都市：现实细节准确度要求
- 悬疑：线索公平性规则
- 言情：情感推进节奏
}}
```

## 使用约束

1. 此模板不固化任何题材风格，所有 `{{}}` 内为占位提示，用户必须自行填写。
2. chapter-writer 写作前必须读取项目 style_guide.md，将其作为硬约束。
3. novel-reviewer 评审时将 style_guide.md 作为风格维度的评判依据。
4. 风格指南修改属于 PROPOSAL → CANON 流程，需用户确认。
5. 未填写的占位符视为"无特殊约束"，不得由 AI 自行填充默认值。
