# Source Policy (for Prompt Generation)

**Skill:** `story-research-prompt`
**Status:** Phase 0 — Frozen Baseline
**Last Updated:** 2026-07-27

---

## 1. 来源优先级（写入提示词）

生成的 Deep Research 提示词必须要求按以下优先级查找资料：

```
原著或官方公开资料
    →
作者、编剧、导演访谈
    →
出版社、制作方和平台资料
    →
学术论文和专业研究
    →
高质量媒体评论
    →
普通影评、书评和社区讨论
```

---

## 2. 禁止来源（写入提示词）

生成的提示词必须明确禁止 Deep Research 使用以下来源：

| 类型 | 说明 |
|------|------|
| 盗版小说站 | 笔趣阁等未授权全文转载 |
| 未授权剧本 | 非官方发布的完整剧本 |
| 破解电子书 | DRM 去除后的文件 |
| 无法确认来源的剧情总结 | 无出处的"剧情介绍" |
| 百科或影评作为原作证据 | 只能作为评论者观点 |

---

## 3. 来源使用规则（写入提示词）

### 3.1 事实检索 vs 分析检索

提示词必须区分两类查询：

| 类型 | 目标 | 示例 |
|------|------|------|
| **事实检索** | 寻找原始资料、出版信息、剧情证据 | "书名 + 出版社"、"作品 + screenplay" |
| **分析检索** | 寻找他人评论与研究 | "书名 + review"、"电影 + analysis" |

两者不能混入同一证据池。

### 3.2 影视类查询模板

提示词应包含以下查询方向：

```
作品名 + 官方剧情简介
作品名 + screenplay / script
作品名 + episode synopsis
作品名 + creator interview
作品名 + ending explained
作品名 + production notes
角色名 + interview
```

### 3.3 小说类查询模板

提示词应包含以下查询方向：

```
书名 + 作者
书名 + 出版社
书名 + 试读
书名 + 目录
书名 + review
书名 + interview
书名 + academic analysis
书名 + public domain / license
```

---

## 4. 来源记录要求（写入提示词）

提示词必须要求 Deep Research 对每个来源记录：

| 字段 | 说明 |
|------|------|
| 来源类型 | 官方/采访/学术/评论/百科/社区 |
| 主要/次要 | 一手资料还是二手资料 |
| 获取日期 | 何时访问 |
| URL | 原始链接 |
| 权威性评分 | 0-1 分 |

---

## 5. 来源冲突处理（写入提示词）

当不同来源信息矛盾时，提示词必须要求：

1. **记录冲突**：不自动选择"正确"的一方
2. **标记优先级**：按来源优先级链标注权威性
3. **写入"资料缺口与不确定结论"章节**：描述冲突内容、双方来源、判断依据
4. **如影响作品消歧**：标记为"低置信度"
