# Purpose & Boundaries

**Skill:** `story-research-prompt`
**Status:** Phase 0 — Frozen Baseline
**Last Updated:** 2026-07-27

---

## 1. Mission Statement

`story-research-prompt` 是一个**研究任务设计器**。它根据用户指定的小说、影视剧、剧本或研究主题，将模糊的研究意图转化为**结构完整、约束明确、适合交给 ChatGPT Deep Research、千问深度研究等工具执行的研究提示词**。

它的核心产物是"**深度研究任务书**"，而不是素材研究包。

---

## 2. In Scope

### 2.1 支持的研究对象

| 类型 | 说明 |
|------|------|
| 单部小说 | 含不同版本、译本 |
| 单部电影 | 含改编对比 |
| 单季电视剧 | 含分集研究 |
| 单部剧本 | 含舞台剧、电视剧本 |
| 研究主题 | 如"悬疑网文的信息控制技巧" |
| 多作品对比 | 含同类型、同作者、改编对比 |

### 2.2 支持的研究模式

| 模式 | 说明 |
|------|------|
| 综合拆书 | 全面分析故事结构、人物、节奏 |
| 故事结构研究 | 聚焦情节推进、因果链、高潮设计 |
| 人物弧光研究 | 聚焦角色发展、关系结构 |
| 悬念与谜题研究 | 聚焦信息控制、误导、伏笔回收 |
| 爽点和节奏研究 | 聚焦网文节奏、情绪设计 |
| 世界观与设定研究 | 聚焦设定系统、规则体系 |
| 影视改编对比 | 聚焦原著与改编的差异 |
| 同类型作品横向研究 | 聚焦可迁移的创作方法 |

### 2.3 生成的提示词包含

- 角色定义（Deep Research 应扮演的角色）
- 任务背景（研究对象和目标）
- 研究问题（可执行的具体问题）
- 来源策略（优先级、禁止来源）
- 证据规则（事实/观点/推断的区分）
- 分析方法（如何整理、对比、建模）
- 输出结构（固定章节）
- 质量检查清单

## 3. Out of Scope

### 3.1 Skill 自己不做的事

- ❌ 访问互联网
- ❌ 下载小说、剧本或字幕
- ❌ 判断具体网站是否合法
- ❌ 执行实际研究
- ❌ 直接生成最终拆书报告
- ❌ 虚构缺失剧情
- ❌ 替 Deep Research 选择最终结论

### 3.2 提示词不要求 Deep Research 做的事

- ❌ 绕过登录、付费墙、DRM
- ❌ 从盗版网站获取内容
- ❌ 自行补全缺失剧情
- ❌ 把推测写成作品设定
- ❌ 把影评当作原作证据

---

## 4. Responsibility Boundary

| 层级 | 职责 | 不做 |
|------|------|------|
| **Skill** | 澄清意图、拆分问题、规划检索方向、规定来源等级、定义证据标准、生成提示词 | 执行研究 |
| **Deep Research** | 执行检索、获取资料、整理证据、生成报告 | 替 Skill 做判断 |
| **用户** | 提供研究对象和目标、确认提示词、执行研究 | 直接让 Skill 出报告 |

---

## 5. Design Principles

1. **意图驱动**：从用户模糊目标出发，拆成可执行的研究问题
2. **约束明确**：提示词必须规定来源优先级、证据规则、输出结构
3. **诚实性**：提示词必须要求 Deep Research 标注资料缺口和不确定结论
4. **可迁移**：提示词应包含"可迁移的创作方法"和"不可照搬的特征"
5. **防污染**：提示词必须要求区分原作事实、主创解释、评论者观点、AI 推断

## 6. v0.1 Frozen Decisions

| # | 决策 |
|---|------|
| 1 | Skill 只生成提示词，不执行研究 |
| 2 | 输出为可直接提交给 Deep Research 的完整提示词 |
| 3 | 支持中文和英文资料 |
| 4 | 提示词必须包含来源策略、证据规则、输出结构 |
| 5 | 提示词必须要求事实与观点分离 |
| 6 | 提示词必须要求标注资料缺口和不确定结论 |
| 7 | 支持 8 种研究模式（综合拆书、结构、人物、悬念、爽点、世界观、改编对比、横向研究） |
| 8 | 提示词生成后必须经过质量审查 |
