# Failure & Degradation Strategy

**Skill:** `story-research-prompt`
**Status:** Phase 0 — Frozen Baseline
**Last Updated:** 2026-07-27

---

## 1. 失败模式分类

### 1.1 输入层失败

| 失败模式 | 触发条件 | 处理策略 |
|---------|---------|---------|
| 空请求 | 未提供目标作品 | 返回错误，要求补充 |
| 歧义过高 | 同名作品 > 5 个且无消歧信息 | 返回候选列表，请求用户选择 |
| 目标过于模糊 | 无法确定研究问题 | 请求用户澄清研究目标 |

### 1.2 提示词生成层失败

| 失败模式 | 触发条件 | 处理策略 |
|---------|---------|---------|
| 问题不可验证 | 研究问题无法通过检索验证 | 重写问题，使其可验证 |
| 来源策略缺失 | 提示词未包含来源优先级 | 阻断输出，补充来源策略 |
| 证据规则缺失 | 提示词未包含事实/观点分离 | 阻断输出，补充证据规则 |
| 输出结构缺失 | 提示词未包含固定章节 | 阻断输出，补充输出结构 |

### 1.3 质量审查层失败

| 失败模式 | 触发条件 | 处理策略 |
|---------|---------|---------|
| 诱导复述 | 提示词可能诱导 Deep Research 大篇幅复述作品 | 修改提示词，要求"概述" |
| 诱导补全 | 提示词未禁止自行补全剧情 | 补充"无法确认"规则 |
| 来源混淆 | 提示词未区分一手/二手来源 | 补充来源分层规则 |
| 结构不完整 | 缺少 14 章中的任何一章 | 补充缺失章节 |

## 2. 降级策略

### 2.1 降级阶梯

```
Level 1: 完整提示词（所有模块 + 全部分析维度）
    ↓ 失败
Level 2: 减少分析维度，保留核心模块
    ↓ 失败
Level 3: 仅生成基础提示词（角色+问题+输出结构）
    ↓ 失败
Level 4: 返回"无法生成"，说明原因
```

### 2.2 研究模式降级

当资料不足以支撑全部维度时：

```
用户请求: 综合拆书（结构+人物+悬念+节奏+世界观）
    ↓
提示词调整为: 聚焦核心维度（结构+人物）
    ↓
输出说明: 其他维度需要更多资料或用户补充
```

## 3. 诚实停止规则

### 3.1 必须停止的情况

- 用户未提供任何研究对象
- 作品消歧置信度 < 0.5 且用户未确认
- 研究目标完全无法理解

### 3.2 停止时输出

```yaml
StopReport:
  status: cannot_generate
  reason: string
  missing_info: []
  recommendation:
    type: enum    | clarify_target | clarify_goal | provide_more_info
    message: string
```

## 4. 异常处理流程

### 4.1 标准流程

```
异常发生
    │
    ├─ 可恢复？
    │   ├─ 是 ─→ 重试生成
    │   └─ 否 ─→ ↓
    ├─ 可降级？
    │   ├─ 是 ─→ 执行降级策略
    │   └─ 否 ─→ ↓
    ├─ 可部分输出？
    │   ├─ 是 ─→ 输出已完成部分 + 失败说明
    │   └─ 否 ─→ 返回完全失败报告
```

## 5. 质量门控

### 5.1 生成后检查清单

提示词生成后必须通过以下检查：

| 检查项 | 阈值 | 失败处理 |
|--------|------|---------|
| 研究对象是否清楚 | 是/否 | 阻断输出 |
| 问题是否可被检索验证 | ≥ 80% | 重写问题 |
| 是否要求事实与观点分离 | 是/否 | 补充规则 |
| 是否规定来源优先级 | 是/否 | 补充来源策略 |
| 是否有明确输出格式 | 是/否 | 补充输出结构 |
| 是否会诱导工具大篇幅复述作品 | 是/否 | 修改提示词 |
| 是否包含创作迁移目标 | 是/否 | 补充模块 |
| 是否要求披露资料缺口 | 是/否 | 补充规则 |

### 5.2 失败报告格式

```json
{
  "status": "generation_failed",
  "generated_at": "2026-07-27T10:00:00Z",
  "target_work": {
    "title": "...",
    "disambiguation_confidence": 0.7
  },
  "failure_reason": "missing_source_policy",
  "completed_modules": [
    "role_definition",
    "research_questions",
    "output_structure"
  ],
  "missing_modules": [
    "source_strategy",
    "evidence_rules"
  ],
  "next_steps": [
    "补充来源策略",
    "重新生成提示词"
  ]
}
```

## 6. 人工介入触发

以下情况应标记为需要人工介入：

- 作品消歧置信度 < 0.7
- 研究目标过于模糊，无法拆成可执行问题
- 用户要求的研究维度超出 Skill 支持范围
- 生成的提示词可能诱导 Deep Research 违反版权政策

**人工介入时输出：**
- 已完成部分的提示词
- 阻塞原因说明
- 建议的解决方案
