# 研究模式定义

**Skill:** `story-research-prompt`
**Phase:** 2 — 研究模式模块
**Last Updated:** 2026-07-27

---

## 1. 模式选择决策树

```
用户研究目标
    │
    ├─ 目标是"全面分析一部作品"？
    │   └─ 是 ─→ 模式 1: 综合拆书
    │
    ├─ 目标是"分析情节/结构"？
    │   └─ 是 ─→ 模式 2: 故事结构研究
    │
    ├─ 目标是"分析人物/角色"？
    │   └─ 是 ─→ 模式 3: 人物弧光研究
    │
    ├─ 目标是"分析悬念/谜题/伏笔"？
    │   └─ 是 ─→ 模式 4: 悬念与谜题研究
    │
    ├─ 目标是"分析节奏/爽点/情绪"？
    │   └─ 是 ─→ 模式 5: 爽点和节奏研究
    │
    ├─ 目标是"分析世界观/设定"？
    │   └─ 是 ─→ 模式 6: 世界观与设定研究
    │
    ├─ 目标是"对比原著与改编"？
    │   └─ 是 ─→ 模式 7: 影视改编对比
    │
    ├─ 目标是"对比多部作品"？
    │   └─ 是 ─→ 模式 8: 同类型作品横向研究
    │
    └─ 无法判断 ─→ 向用户确认或默认综合拆书
```

## 2. 模式 1: 综合拆书（Comprehensive Analysis）

### 2.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 全面分析一部作品的故事机制 |
| **适用场景** | 首次研究一部作品，希望获得完整认知 |
| **研究范围** | 结构 + 人物 + 悬念 + 节奏 + 世界观 |

### 2.2 角色定义定制

在通用角色基础上，额外强调：
- 跨维度关联分析能力（如发现"人物弧光如何影响节奏"）
- 整体性视角（不孤立分析单个维度）

### 2.3 研究问题集

```markdown
# 研究问题

## 故事结构
1. 作品的核心概念是什么？一句话概括。
2. 整体采用什么结构模型？（如三幕结构、英雄之旅、多线并行等）
3. 核心冲突是什么？如何建立、升级和解决？
4. 有哪些关键转折点？每个转折点如何改变故事方向？
5. 高潮设计有何特点？如何铺垫和释放？

## 人物与关系
6. 主角的核心欲望和恐惧是什么？
7. 主角经历了怎样的内在变化？变化的关键节点是什么？
8. 角色关系网络呈现什么结构？哪些关系是核心驱动力？
9. 反派/对立力量的设计有何特点？与主角形成什么对照？

## 悬念与信息控制
10. 核心谜面是什么？如何建立？
11. 真相如何分阶段揭示？每个阶段揭示什么？
12. 读者与角色掌握的信息是否一致？何时产生信息差？
13. 误导如何建立和回收？关键伏笔有哪些？

## 节奏与情绪
14. 整体情绪曲线呈现什么形态？
15. 爽点/高潮的间隔和强度如何分布？
16. 信息密度如何变化？哪里是"加速段"哪里是"缓冲段"？

## 世界观与设定
17. 核心设定是什么？设定如何影响情节？
18. 设定规则是否有明确的边界和代价？
19. 设定是否为情节服务，还是情节为设定服务？
```

### 2.4 输出结构侧重

14 章全部保留，但侧重：
- **第 4 章**（核心故事机制）：核心章节
- **第 7 章**（悬念、谜题与信息控制）：核心章节
- **第 11 章**（可迁移的创作方法）：综合提炼

## 3. 模式 2: 故事结构研究（Structure Analysis）

### 3.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦情节推进、因果链、高潮设计 |
| **适用场景** | 学习"如何把故事讲得清楚、有张力" |
| **研究范围** | 情节节点、因果关系、结构模型、转折设计 |

### 3.2 角色定义定制

在通用角色基础上，额外强调：
- 情节逻辑分析能力
- 结构模型识别能力（三幕、英雄之旅、起承转合等）

### 3.3 研究问题集

```markdown
# 研究问题

## 核心概念与结构
1. 作品的核心概念是什么？一句话概括。
2. 整体采用什么结构模型？各阶段如何划分？
3. 核心冲突是什么？冲突双方分别代表什么价值观/利益？

## 情节与因果链
4. 列出前 10 个关键情节节点，每个节点一句话概括。
5. 相邻节点之间是否存在"所以"或"但是"的因果关系？
6. 哪些节点是"不可逆转的转折点"？转折前后的故事方向有何不同？
7. 情节密度在不同阶段如何变化？哪里密哪里疏？

## 高潮与解决
8. 高潮是什么？如何铺垫？（列出铺垫节点）
9. 高潮解决的核心冲突是什么？用了什么方法？
10. 结局是闭合还是开放？给读者留下什么？

## 结构创新
11. 作品在结构上有何独特之处？（如非线性叙事、多视角、倒叙等）
12. 这种结构对读者理解故事有何影响？
```

### 3.4 输出结构侧重

14 章中保留核心：
- **第 4 章**（核心故事机制）：核心章节
- **第 6 章**（情节推进与因果链）：核心章节
- **第 8 章**（情绪节奏与高潮设计）：重点分析高潮

---

## 4. 模式 3: 人物弧光研究（Character Arc Analysis）

### 4.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦角色发展、关系结构、弧光设计 |
| **适用场景** | 学习"如何让人物立体、有成长" |
| **研究范围** | 角色欲望、恐惧、变化、关系网络 |

### 4.2 角色定义定制

在通用角色基础上，额外强调：
- 心理分析能力（理解角色内在动机）
- 关系网络分析能力（理解角色间的动力学）

### 4.3 研究问题集

```markdown
# 研究问题

## 主角分析
1. 主角的核心欲望是什么？（外在目标 vs 内在需求）
2. 主角的核心恐惧/缺陷是什么？如何阻碍他？
3. 主角在故事开头 vs 结尾有何变化？（内在变化）
4. 变化的关键节点是什么？每个节点触发了什么？
5. 主角的"信念"是否改变？如何改变？

## 配角分析
6. 最重要的 3 个配角分别是什么功能？（如导师、伙伴、对手、阴影等）
7. 配角如何推动主角的变化或阻碍主角？
8. 有没有配角自身的弧光？与主角弧光如何呼应？

## 反派/对立力量
9. 反派/对立力量的核心欲望是什么？
10. 反派与主角形成什么对照？（如镜像、相反价值观）
11. 反派是否具有"合理性"？读者是否能理解其行为逻辑？

## 关系网络
12. 核心关系有哪些？每条关系的起点、转折、终点是什么？
13. 关系变化如何推动情节？举 3 个关键例子。
14. 有没有"关系三角"？三角关系如何影响角色选择？
```

### 4.4 输出结构侧重

14 章中保留核心：
- **第 5 章**（人物与关系结构）：核心章节
- **第 11 章**（可迁移的创作方法）：聚焦人物塑造方法

---

## 5. 模式 4: 悬念与谜题研究（Mystery & Suspense Analysis）

### 5.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦信息控制、误导、伏笔回收 |
| **适用场景** | 学习"如何控制读者信息、制造悬念" |
| **研究范围** | 谜面、真相揭示、信息差、伏笔、误导 |

### 5.2 角色定义定制

在通用角色基础上，额外强调：
- 信息论视角（理解"谁知道什么、何时知道"）
- 误导机制识别能力

### 5.3 研究问题集

```markdown
# 研究问题

## 核心谜面
1. 核心谜面是什么？如何建立？（何时、如何向读者呈现问题）
2. 谜面的"表面问题"和"深层问题"分别是什么？
3. 哪些角色知道谜底？哪些不知道？何时知道的？

## 真相揭示节奏
4. 真相分几个阶段揭示？每个阶段揭示什么？
5. 每个揭示节点之间有什么逻辑关联？
6. 有没有"伪真相"或"部分真相"？如何误导读者？

## 信息控制机制
7. 读者与角色掌握的信息是否一致？
8. 何时产生信息差？（读者比角色知道更多 / 角色比读者知道更多）
9. 信息差的制造手法是什么？（如视角限制、时间差、角色隐瞒等）

## 伏笔与误导
10. 列出 5 个关键伏笔，说明如何铺垫、何时回收。
11. 误导如何建立？（如错误线索、错误解释、注意力引导）
12. 误导回收时，读者可能产生什么反应？（惊讶 / 恍然 / 重新解读）

## 悬念类型
13. 作品主要依赖哪种悬念？（结果悬念 / 过程悬念 / 身份悬念等）
14. 悬念的强度如何变化？高峰出现在哪里？
```

### 5.4 输出结构侧重

14 章中保留核心：
- **第 7 章**（悬念、谜题与信息控制）：核心章节
- **第 9 章**（伏笔、误导和回收）：核心章节
- **第 11 章**（可迁移的创作方法）：聚焦悬念设计方法

## 6. 模式 5: 爽点和节奏研究（Pacing & Satisfaction Analysis）

### 6.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦网文节奏、情绪设计、爽感机制 |
| **适用场景** | 学习"如何设计爽点、控制叙事节奏" |
| **研究范围** | 情绪曲线、爽点间隔、信息密度、升级体系 |

### 6.2 角色定义定制

在通用角色基础上，额外强调：
- 网文/类型文学的特殊节奏感知
- 爽感机制分析能力（理解"为什么这里爽"）

### 6.3 研究问题集

```markdown
# 研究问题

## 情绪曲线
1. 整体情绪曲线呈现什么形态？（可绘制：横轴为章节/时间，纵轴为情绪强度）
2. 情绪高峰和低谷分别出现在哪里？对应什么情节？
3. 情绪节奏是否有规律？（如"小爽-缓冲-大爽"循环）

## 爽点设计
4. 列出前 10 个关键爽点，每个爽点是什么类型？（如打脸、升级、揭秘、逆袭等）
5. 每个爽点的铺垫用了多久？（章节数/时间）
6. 爽点的强度如何递进？（小爽 → 中爽 → 大爽）
7. 爽点之间的"期待感"如何维持？

## 升级体系
8. 作品是否有明确的升级体系？（如等级、能力、地位）
9. 升级的触发条件是什么？升级后带来什么变化？
10. 升级节奏如何控制？（太快会无聊，太慢会焦虑）

## 信息密度与节奏
11. 信息密度在不同阶段如何变化？
12. "加速段"和"缓冲段"如何交替？
13. 有没有"信息过载"或"节奏拖沓"的问题？

## 网文特有机制
14. 是否使用"章末钩子"？如何使用？
15. 是否使用"金手指"？金手指的边界和代价是什么？
16. 是否使用"装逼打脸"循环？如何变化避免重复？
```

### 6.4 输出结构侧重

14 章中保留核心：
- **第 8 章**（情绪节奏与高潮设计）：核心章节
- **第 11 章**（可迁移的创作方法）：聚焦节奏和爽点设计方法

## 7. 模式 6: 世界观与设定研究（Worldbuilding Analysis）

### 7.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦设定系统、规则体系、设定与情节的互动 |
| **适用场景** | 学习"如何构建世界观、让设定服务于故事" |
| **研究范围** | 设定体系、规则边界、设定-情节互动 |

### 7.2 角色定义定制

在通用角色基础上，额外强调：
- 系统思维（理解设定的内在一致性）
- 设定-情节互动分析能力

### 7.3 研究问题集

```markdown
# 研究问题

## 设定体系
1. 核心设定是什么？（如魔法系统、超能力、未来科技等）
2. 设定的基本规则是什么？列出 3-5 条核心规则。
3. 设定的边界和代价是什么？（不能做什么 / 使用设定需要什么代价）
4. 设定是否有明确的升级/变化机制？

## 设定与情节的互动
5. 设定如何驱动情节？（设定 → 情节 vs 情节 → 设定）
6. 举 3 个例子，说明设定如何创造独特的冲突或解决方案。
7. 有没有"设定伏笔"？（早期引入的设定在后期发挥关键作用）

## 设定的呈现方式
8. 设定如何向读者呈现？（如逐步揭示、开篇说明、通过角色学习）
9. 有没有"设定说明"过于集中的问题？
10. 设定信息是否融入情节自然传达？

## 设定的内在一致性
11. 设定是否存在矛盾或漏洞？
12. 设定规则是否被一致遵守？有没有"为剧情需要打破规则"的情况？
13. 这种打破是否被读者接受？为什么？
```

### 7.4 输出结构侧重

14 章中保留核心：
- **第 4 章**（核心故事机制）：聚焦设定如何驱动故事
- **第 6 章**（情节推进与因果链）：聚焦设定创造的独特因果关系
- **第 11 章**（可迁移的创作方法）：聚焦世界观构建方法

## 8. 模式 7: 影视改编对比（Adaptation Comparison）

### 8.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦原著与改编的差异及其对故事机制的影响 |
| **适用场景** | 学习"如何把小说改编为影视/如何理解改编取舍" |
| **研究范围** | 情节差异、人物差异、媒介差异、改编策略 |

### 8.2 角色定义定制

在通用角色基础上，额外强调：
- 媒介差异理解（小说 vs 电影 vs 电视剧的表现手法差异）
- 改编决策分析能力（理解"为什么这样改"）

### 8.3 研究问题集

```markdown
# 研究问题

## 改编范围
1. 改编版本有哪些？（如电影版、电视剧版、不同国家版本）
2. 每个改编版本的年份、导演/编剧、主要演员是谁？
3. 改编的"忠实度"如何？（完全忠实 / 松散改编 / 仅保留概念）

## 情节差异
4. 哪些情节被删除？为什么可能删除？（媒介限制、时长、观众等）
5. 哪些情节被新增？新增的目的是什么？
6. 哪些情节被修改？修改前后的效果有何不同？
7. 结构是否改变？（如非线性改为线性、视角变化）

## 人物差异
8. 哪些角色被合并、删除或新增？
9. 角色关系是否变化？变化对故事有何影响？
10. 主角的弧光是否改变？如何改变？

## 媒介差异
11. 小说擅长的表现手法，改编后如何呈现？
12. 影视擅长的表现手法，如何利用？（如视觉、音乐、表演）
13. 有没有"跨媒介失败"的地方？（小说无法转化为视觉 / 影视无法表达内心）

## 改编策略
14. 改编的核心策略是什么？（如简化、现代化、本土化）
15. 创作者（导演/编剧）在访谈中如何解释改编决策？
```

### 8.4 输出结构侧重

14 章中保留核心：
- **第 3 章**（故事整体概述）：分别概述原著和改编
- **第 4 章**（核心故事机制）：聚焦差异分析
- **第 10 章**（作品成功与不足）：聚焦改编成败
- **第 11 章**（可迁移的创作方法）：聚焦改编方法论

## 9. 模式 8: 同类型作品横向研究（Comparative Analysis）

### 9.1 概述

| 维度 | 说明 |
|------|------|
| **定位** | 聚焦多部作品间的共性与差异，提炼可迁移方法 |
| **适用场景** | 学习"同类型作品有哪些共同规律、如何创新" |
| **研究范围** | 类型特征、共同机制、差异点、创新点 |

### 9.2 角色定义定制

在通用角色基础上，额外强调：
- 类型文学/类型片知识
- 跨作品比较分析能力

### 9.3 研究问题集

```markdown
# 研究问题

## 类型定义
1. 这些作品属于什么类型/子类型？
2. 该类型的核心特征是什么？（套路、期待、观众群体）
3. 这些作品是否满足类型期待？如何满足？

## 共同机制
4. 在故事结构上，这些作品有什么共同点？（如都采用三幕结构）
5. 在人物塑造上，这些作品有什么共同点？（如都有"导师"角色）
6. 在悬念设计上，这些作品有什么共同点？（如都使用信息差）
7. 在节奏设计上，这些作品有什么共同点？（如都遵循"小爽-大爽"循环）

## 差异与创新
8. 哪部作品在结构上有创新？创新效果如何？
9. 哪部作品在人物塑造上有创新？
10. 哪部作品在类型融合上有创新？（如悬疑+喜剧）

## 可迁移方法
11. 从这些作品中可以提炼出什么通用创作方法？
12. 每种方法的适用条件是什么？
13. 如何在这些方法的基础上进行创新？

## 类型演变
14. 从最早到最新的作品，该类型发生了哪些演变？
15. 演变的驱动力是什么？（观众审美、社会文化、市场竞争）
```

### 9.4 输出结构侧重

14 章中保留核心：
- **第 4 章**（核心故事机制）：聚焦共同机制
- **第 10 章**（作品成功与不足）：聚焦差异和创新
- **第 11 章**（可迁移的创作方法）：核心章节，系统提炼

## 12. 模式组合

### 12.1 组合场景

当用户说"既要分析结构，也要分析人物"时：
1. 选择主要模式（如结构）
2. 从次要模式（人物）中补充研究问题
3. 在输出结构中合并两个模式的核心章节

### 12.2 组合限制

- 最多组合 2 个模式（避免问题过多）
- 组合时优先保留各自的核心研究问题
- 合并时去除重复的问题
