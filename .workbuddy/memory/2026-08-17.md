# 2026-08-17 工作日志

## 创建 skill-sync.ps1（Skill 同步工具）

在 workspace 根目录新增 `skill-sync.ps1`，用于把 workspace 注册的 Skill 通过 Windows Junction 链接同步到多个目标 Agent 的 Skills 目录。

**功能**：JSON 清单 `skill-sync.json`（agents + skills 两组列表，均含 enabled 标志）+ 子命令：
- `init`（初始化清单，-Force 覆盖）、`scan`（扫描根目录含 SKILL.md 的目录自动注册）
- `list`/`status`（清单/实际链接状态）、`sync`（建链接，-Force 重建过期链接）、`unsync`（只删链接不动源，需确认或 -Force）
- `add`/`remove`/`enable`/`disable`（skill 增删启用）、`agent add/remove/enable/disable/list`（agent 任意增删）
- 无参数进入彩色交互菜单；退出码：0 成功 / 1 有失败

**设计要点（踩坑记录）**：
- 脚本保存为 **UTF-8 BOM**，否则 PS 5.1 读无 BOM 中文会乱码
- 配置读写统一用 `[IO.File]::ReadAllText/WriteAllText` 显式 UTF8（PS5.1 的 Get-Content/Out-File 默认编码会出问题；写 JSON 用 UTF8 BOM，ConvertFrom-Json 读回空数组变 $null 需补 `@()`）
- `Remove-Item -Recurse` 对 Junction 只删链接本身不删目标（PS5.1+ 安全行为）；删除前先校验 `LinkType -eq 'Junction'`
- 路径比较：`[IO.Path]::GetFullPath().TrimEnd('\')` + `-ieq`（防大小写/尾部斜杠差异）
- `New-Item -ItemType Junction` 无需管理员权限

**验证**：隔离临时环境 50 项集成测试全部通过（init/幂等/重复添加拒绝/Blocked/Stale/-Force 重建/unsync 源保留/配置损坏/缺失目录自动创建等），并单独验证 pwsh 7 核心流程兼容。未在真实 workspace 执行 init（由用户自行决定初始化时机）。
